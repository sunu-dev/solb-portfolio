# 2026-07-19 - 가격 가설 검증 기반과 시장성 재검토

## 작업 요약

결제 기능을 만들기 전에 적격 사용자의 실제 행동으로 월 4,900원 가설을 검증할 수 있는 내부 기반을 구현했다. 보유 종목이나 자산 금액을 서버로 보내지 않고, 가격 화면 노출·열기·시작·대기 신청·닫기 이벤트만 인증된 API로 수집한다. `/admin`의 `PRO 준비`에는 이벤트를 남기지 않는 미리보기와 코호트별 지표를 추가했다.

시장성은 2026-07-19 기준 공식 자료와 현재 경쟁 서비스를 다시 비교했다. 결과는 `docs/MARKET_VIABILITY_2026-07-19.md`에 정리했다.

## 결정사항

아래 시장 전략 결정은 사용자 승인 후 auto-memory의 `project_record_operations_strategy.md`로 승급했다. 이 세셔너리에는 당시 흐름을 남기고, 이후 적용 시에는 메모리를 최신 SSOT로 본다.

- 범용 AI 주식비서 포지셔닝은 대형 플랫폼·증권사·범용 AI와 정면 경쟁하므로 NO-GO로 본다.
- 주비는 여러 증권사 투자 기록을 합치고, 중복을 정리하고, 잘못 바뀐 기록을 복구하는 개인 투자 기록 운영도구로 좁힌다.
- 투자정보와 AI, 기본 CSV·JSON 내보내기는 무료와 PRO가 동일하다.
- PRO의 첫 결제 이유는 자동 백업·버전 복구, 여러 파일 OCR·중복 확인, 월간 가치 영수증으로 검증한다.
- 월 4,900원은 확정 가격이 아니라 행동 실험용 가설이다.
- 운영 노출은 이벤트 DB, 개인정보 처리방침 준비, 두 환경 플래그가 모두 갖춰진 경우에만 허용한다. 하나라도 빠지면 설정·이벤트 API가 fail-closed로 동작한다.
- 운영 마이그레이션과 실제 결제는 이번 세션에서 적용하지 않았다.

## 주비 아이콘 교체

사용자가 제공한 붉은 곡선 표식을 형태 변경 없이 채택했다. 원본의 과도한 여백과 우측 하단 생성 도구 워터마크는 정사각형 크롭으로 제외했다. 일반 192·512 아이콘, 운영체제 마스크 안전 여백을 둔 별도 192·512 아이콘, 32px 파비콘을 만들고 헤더·랜딩·공유 이미지의 기존 J/S 표식을 교체했다. 랜딩에 남아 있던 기본 이모지도 제거했다. 기존 청록색 UI 테마는 아이콘 변경과 분리해 유지했다.

후속 요청으로 `주비` 워드마크도 붉은색으로 바꿨다. 라이트는 접근성을 고려한 `#E60012`, 다크는 `#FF6670`이며 `--brand-wordmark` 전용 토큰으로 관리한다. 로그인 창에 남아 있던 구형 청록 J 아이콘도 새 이미지로 교체했다. 버튼·탐색 등 정보 UI의 Mossy Teal과 손익 빨강은 그대로 분리한다. 이 영속 결정은 사용자 승인에 따라 auto-memory `project_design_system.md`로 승급했으며, 상세 SSOT는 메모리를 본다.

워드마크를 실제 확인한 뒤 파운더가 붉은 글자를 철회했다. 최종안은 붉은 곡선 아이콘 + 검정 외곽선만 있고 내부가 투명한 `주비` 조합이다. 본문 Pretendard와 구분되는 굵은 시스템 한글 스택을 사용하며, 다크모드에서는 외곽선을 밝게 반전한다. 이전 붉은 워드마크 기록은 경과이며 최신 SSOT는 현행화한 디자인 메모리를 본다.

첫 아웃라인 시안은 macOS의 Apple SD Gothic Neo가 잡혀 작고 올드하게 보인다는 피드백을 받았다. 별도 폰트 다운로드 없이 이미 로드되는 `Pretendard Variable` 900축으로 교체하고, 자간을 `-0.035em`, 외곽선을 1.4px로 조정했다. 헤더 22px·랜딩 24px·로그인 26px·초기 로딩 20px로 키웠다. 디자인 메모리의 워드마크 사양도 이 값으로 현행화했다.

후속 피드백에서 크기뿐 아니라 글자 골격 자체 변경을 요청했다. Next.js 16.2.1의 공식 `next/font/google` 지원을 확인한 뒤 `Gasoek One`을 워드마크 전용 변수로 추가했다. 빌드 시 자체 호스팅되며 브라우저가 Google에 직접 요청하지 않는다. 내부 투명·아웃라인 구조는 유지하고 자간 `-0.02em`, 외곽선 1.25px로 조정했다. ESLint·사전 린트·TypeScript·프로덕션 빌드를 통과했고 로컬 서버를 갱신했다.

최종 아이디어는 별도 `주비` 단어 대신 한 문장 `나만의 주식비서` 안에서 `주·비`만 크게, `나만의·식·서`는 작게 보여 서비스 설명과 브랜드명을 동시에 읽히게 하는 방식이다. 디자인 에이전트는 분절·모바일 폭·작은 아웃라인 가독성을 이유로 수정 후 GO를 제시했다. 이를 반영해 `JoobiLockup` 공용 컴포넌트를 만들고 헤더 29/13px, 랜딩 42/18px, 로그인 34/14px, 로딩 32/13px 변형을 적용했다. 640px 이하 헤더는 작은 글자를 숨겨 큰 `주비`만 남긴다. ESLint·사전 린트·TypeScript·프로덕션 빌드를 통과하고 로컬 서버를 갱신했다.

파운더 확인 후 작은 글자의 중앙 정렬을 하단 정렬로 바꿨다. `나만의·식·서`는 헤더 9px, 랜딩 12px, 로그인 10px, 로딩 9px로 더 줄이고 큰 `주·비`의 아래 끝에서 2px 위에 맞췄다. 프로덕션 빌드 통과 후 로컬 서버를 갱신했다.

검증은 이미지 크기·크롭 육안 확인, `git diff --check`, 대상 ESLint, 한국어·다크모드·투어 앵커 검사, TypeScript와 Next.js 16.2.1 프로덕션 빌드 통과다. 로컬 프로덕션 서버에서 랜딩·아이콘·공유 이미지 API가 모두 HTTP 200이며, 생성된 공유 PNG에도 새 표식이 정상 렌더링되는 것을 확인했다. 워드마크 변경 후 첫 빌드는 샌드박스의 Google Fonts 네트워크 차단으로 실패했지만 네트워크 허용 재실행에서는 정상 통과했다.

## AI 인사이트 기본 이모지 제거

사용자 지적에 따라 AI 인사이트 상단과 바로가기의 `🤖·🎯·💬·🌐·🔥·🪞`를 Lucide 선형 아이콘으로 교체했다. 퀴즈 완료 후 다시 나타나던 투자 유형 이모지는 `InvestorTypeIcon` 공용 매핑으로 바꾸고, 숨은 종목·회고·포트폴리오 DNA·종목 맥박·투자 일기 등 같은 화면의 하위 카드도 정리했다. 이야기 본문의 장식 이모지도 제거했다. OS별 기본 이모지가 재유입되지 않도록 AI 인사이트 주요 8개 화면을 검사하는 `uiIconPolicy.test.ts` 회귀 테스트를 추가했다.

검증은 아이콘 정책 테스트 8건, 변경 핵심 컴포넌트 ESLint, `git diff --check`, 사전 린트·TypeScript·Next.js 프로덕션 빌드 통과다. 전체 대상 ESLint에서는 이번 변경과 무관한 기존 `Date.now()` 렌더 순수성 및 SettingsPanel effect 규칙 오류가 확인됐으며 새 아이콘 코드에서는 오류가 없었다. 최신 빌드는 `http://localhost:3000`에 다시 실행했다.

## 워드마크 채움형 전환과 폰트 10안

파운더가 빈 아웃라인보다 내부가 채워진 검정 워드마크를 선택했다. 공용 `JoobiLockup`의 문장 구조·크기·하단 정렬은 그대로 두고 `주·비`만 검정 채움형으로 전환했으며, 다크모드에서는 밝은 채움색으로 반전한다.

폰트 골격만 비교할 수 있도록 `/brand-preview` 내부 페이지에 10개 후보를 같은 아이콘·문장·크기·정렬로 배치했다. 처음에는 후보 전체를 `next/font/google`로 불러왔으나 한국어 유니코드 범위 파일을 수백 개 생성해 빌드 비용이 과도해졌다. 이를 폐기하고 Google Fonts의 `주비` 두 글자 서브셋만 자체 호스팅하는 방식으로 바꿨다. 10개 합계는 약 56KB이며 비교 페이지는 검색 제외 처리했다. 최종 선택 후 선택하지 않은 9개와 미리보기 페이지를 제거하고 선택 폰트의 원본 라이선스를 보관한다.

사전 린트·TypeScript·Next.js 16.2.1 프로덕션 빌드를 통과했고 `/brand-preview`와 대표 폰트 파일의 HTTP 200을 확인했다. 자동 브라우저 화면 검증은 런타임 kernel assets 오류로 수행하지 못해 파운더 육안 선택이 남았다.

파운더는 첫 10안 중 10번 `Single Day`의 손글씨 인상을 선호했다. 이에 기존 후보 9개를 폐기하고 Single Day를 기준으로 Gaegu, Nanum Pen Script, Gamja Flower, Hi Melody, Poor Story, Yeon Sung, Stylish, Cute Font, Kirang Haerang까지 유사 계열 10안으로 다시 구성했다. 비교의 일관성을 위해 큰 `주·비`뿐 아니라 작은 `나만의·식·서`도 각 후보와 동일한 폰트를 사용한다. 문장 전체 서브셋 10개는 약 556KB이며 비교 페이지에서만 로드된다. 프로덕션 빌드와 `/brand-preview` 및 대표 폰트 3개의 HTTP 200을 확인했다.

유사 손글씨 10안도 2000년대 초 인상이라는 파운더 피드백을 받아 손글씨 방향을 폐기했다. 비교 화면을 현대적 1안 `IBM Plex Sans KR 700`, MZ 소프트 1안 `Bagel Fat One`, MZ 그래픽 1안 `Gasoek One`의 3안으로 재구성하고 이전 손글씨 자산을 제거했다. 세 안 모두 `나만의 주식비서` 전체에 동일 폰트를 적용한다. 프로덕션 빌드와 페이지·폰트 3개 HTTP 200을 확인했다.
