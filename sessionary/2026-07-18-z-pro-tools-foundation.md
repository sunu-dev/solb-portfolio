# 2026-07-18 - 도구형 PRO 내부 기반

## 작업 요약

기존 무료 투자정보·AI 기능은 그대로 유지하면서, 신고·등록 위험을 불필요하게 키우지 않는 비투자 도구형 PRO의 내부 기반을 구현했다.

- PRO 상품 SSOT와 도구 권한 모델 추가
- 서버 권위 권한 조회 API와 관리자 준비도 API 추가
- 구독 상태 전이·만료·결제 실패 유예 알고리즘 추가
- 결제 이벤트 멱등성과 서비스 역할 전용 쓰기를 고려한 DB 마이그레이션 초안 추가
- 관리자 화면에 PRO 준비 상태와 판매 잠금 표시 추가
- CSV·JSON 포트폴리오 내보내기 기반과 스프레드시트 수식 주입 방어 추가
- PRO에서도 AI 횟수·품질·속도·시장정보·시세 신선도를 무료와 동일하게 유지하는 회귀 테스트 추가
- 결제·법률·사업자·정책·복구·관측·지원 준비가 모두 확인되기 전에는 판매가 열리지 않는 fail-closed 게이트 추가

전체 테스트 144개 통과, 1개 스킵, TypeScript·변경 파일 ESLint·diff check·프로덕션 빌드가 통과했다. 결제 SDK·체크아웃·웹훅 운영 코드와 DB 마이그레이션 적용은 하지 않았다.

## 결정사항

- PRO는 투자정보의 우열이 아니라 내보내기, 이력, 백업, 일괄 작업, 화면 프리셋, 광고 제거 같은 편의 도구에만 과금한다.
- 무료와 PRO의 AI 분석 횟수·품질·속도, 시장 해설, 시세 신선도, 투자 알림, 종목 선정은 동일하게 유지한다.
- 내부 가격 가설은 월 4,900원·연 49,000원이지만 판매 검증 전 확정 가격이 아니다.
- 기존 수동 PRO 사용자는 호환을 위해 유지하되, 판매 전 수동 권한 전수 감사가 필수다.
- 구독 권한은 서버가 판정하고, 상태나 기간이 불완전하면 권한을 닫는 방식으로 처리한다.
- 결제 기능 장애가 무료 투자정보 기능에 영향을 주지 않도록 결제 경로를 분리한다.
- 운영 DB 적용, 결제사 선택, 공개 판매는 파운더 승인과 법률·사업·정책 게이트 완료 후에만 한다.
