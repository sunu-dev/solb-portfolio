## 작업 요약
- 사용자는 주식사전 기존 문구와 디자인을 거절. 먼저 공통 구조를 정해 구현하지 말고, 전혀 다른 시안 10개를 제시해 직접 선택하게 해 달라고 정정했다.
- 첫 A–J 목록/검색/카드/폴더/노트/대화/종목/복습/비교/사이드창 시안도 거절했다. 사용자 선호: 귀엽고 아기자기한 아날로그 느낌, 기존 새싹 주비 캐릭터 활용.
- 새 시안 A 링 수첩 / B 카드함 / C 스크랩북 / D 편지 / E 도서관 / F 메모 보드 / G 포켓 바인더 / H 작은 책상 / I 클립보드 / J 미니 수첩. 기존 새싹 PNG와 주비 Single Day 글꼴 사용. 본문은 시스템 글꼴 유지.
- 실제 계정 없는 정적 시안이며 운영 코드·DB·배포 변경 없음. 이전 버전도 artifacts에 보존.

## 결정사항
- 사용자 선택 전 운영 UI 적용 및 최종 디자인 시스템 확정하지 않는다. 서로 다른 구성의 시안을 보여주고 선택/조합을 받는다.
- 장식은 새싹·종이·테이프·클립으로 구현하되 설명·실제 버튼을 가리지 않는다. 캐릭터는 접근성상 장식.
- 최종 선택 후 기존 용어·사전 저장 로직을 공유하고 PC 전체/모바일 더보기에 독립 사전 메뉴 연결한다.
- 추가 사용자 제안: 일반 화면은 별칭, 카카오 이름은 내 정보에서만 확인. UserMenu 현재 full_name→name→이메일 앞부분이므로 아직 구현된 것이 아님. 별칭이 없어도 첫 이용 강제 입력 없이 중립 문구 사용 제안.
