## 결정사항

- **§6 판정 근거를 조문으로 교정했다.** 그동안 쓰던 '개별성·특정성·매매권유 3요건'은 내부 위험
  모델이지 법조문이 아니다. **자본시장법 제7조 제3항**이 "간행물·통신물 등을 통한 **개별성 없는
  조언**"을 투자자문업에서 **명시적으로 제외**한다(예외: 유료 고객과 온라인 의견교환).
  → 모두에게 동일한 정적 일방향 팁은 **지금보다 깊게 설명할 수 있다**. 원문 확인함.
- **깊이의 한계는 "방향 대신 계산 원리"다.** "금리 상승 → 성장주 부담"은 위험,
  "할인율 가정이 바뀌면 계산 결과가 달라진다"는 안전. 상품군에 방향·경사를 붙이는 순간 넘는다.
- **푸시는 법이 아니라 제품 정책이 막는다.** 법적으로는 사실 통지(일정·결과)까지 여지가 있으나
  `Status≠Alert` 원칙상 NO-GO. 게다가 BLS 6h 캐시라 '발표 즉시 푸시'가 기술적으로 불가.
  열려면 정책 SSOT 변경이 선행돼야 한다.
- **지표는 라벨이 곧 정확성이다.** 일본은 BOJ가 주는 `기준대출이율`(1.25%)이 더 깔끔한 숫자지만
  뉴스의 '금리 인상'과 다른 지표다. 정확한 시리즈(무담보 콜 O/N 0.977%)를 골랐고,
  그마저 **목표(1.0%)가 아닌 실현치**라 라벨을 '일본 단기금리'로 정정하고 차이를 교육 카피에 넣었다.
- **1차 출처를 열지 않았으면 틀린 수치가 들어갈 뻔했다.** 웹 검색은 BOJ 정책금리를 1.25%로
  보고했는데, 성명서 PDF 원문을 열어보니 **다카타 위원의 부결된 반대 제안**이었다(실제 목표 1.0%).
- **재감사 실패는 '통과'가 아니다.** 에이전트가 전멸해 `findings: []`가 나온 것을 결함 없음으로
  읽으면 검증 없이 배포된다. 실제로 재실행하니 §6 가드가 뚫려 있었고 화면에 자기모순 표기가 나가고 있었다.
- **카피에 새 대상어가 등장하면 가드 어휘도 함께 늘려야 한다.** 일본 카드가 '한국 증시'를 처음 쓰면서
  그 단어가 가드에 없어 인과문 13/14가 통과했다. 배포 카피는 무결했지만 **다음 편집자를 막지 못하는 상태**였다.
- **계산 자릿수와 표시 자릿수는 같아야 한다.** 3자리 계산 → 2자리 표시가 '-0.00%p'라는
  자기모순을 만들었다. usTreasury는 애초에 일치시켜 뒀고 일본 경로만 계약이 깨져 있었다.
- **전역 lint 승격은 실측으로 판단한다.** 매크로 정책을 전역으로 올리면 기존 src 172줄이 걸린다
  (`평단`·`비중`은 정당한 포트폴리오 라벨). SSOT 파일 한정으로 두고 사각을 주석에 명시했다.

## 이번 세션이 만든 결함과 발견 경로

자체 수정이 만든 결함을 검증 장치가 잡은 사례 — 다음 세션이 같은 함정을 피하도록.

1. **FRED 빈 문자열 결측이 0으로 통과** — `Number('')===0`이라 "기준금리 0.00~3.50%"가 표시될 수 있었다.
   `.`만 막던 초판 가드가 원천의 실제 포맷에서 무력. → 적대 재감사가 발견, 재현으로 확정.
2. **`cosd`가 다중 시리즈에서 무시** — 매번 6,457행 수신, 그 첫 행이 위 결측 행이었다.
   단일 시리즈 2회로 전환하니 둘 다 해소(150KB→1KB).
3. **BLS 일 25회 한도 노출** — 모듈 캐시는 인스턴스별·CDN은 PoP별이라 30분 캐시로 하루 48회
   재검증이 가능. TTL 6h + in-flight dedup + 부분 실패 짧은 캐시로 조임.
4. **CPI 행 375px 폭 초과** — 값+부가+기준을 한 줄 nowrap으로 묶은 게 원인. 2단 레이아웃으로.
   '전월 +3.5%'가 **월간 3.5% 상승(초인플레)으로 오독**돼 '전월 발표'로 명시.
5. **`/api/us-treasury`가 소비자 0** — 티커를 통합 엔드포인트로 옮기면서 발생. 라우트 삭제
   (도달 불가 코드를 남기지 않는다 — 전일 MacroStrip 교훈).

### 4. 일본 재감사 재실행 (PR #37, `721122b`)

직전 재감사가 절전·에이전트 정지로 전멸(`findings: []` = **검증 못 함**)해 재실행. 15/15 완주, 발견 22건.
실재 확정분을 **직접 재현한 뒤** 5건 수정.

- **§6 가드 사각(높음)** — 일본 카드가 카피 SSOT에 **'한국 증시'를 처음 등장시켰는데**
  그 대상어가 가드 어휘에 없었다. 내 프로브 실측 5/6 탈출
  ('엔캐리 청산 국면에서는 코스피가 흔들려요'조차 방향어 미등재로 통과).
  상품어·방향어·조건절 보강 → **탈출 0/10 · 과차단 0/5**.
- **자기모순 표기(높음)** — `changePp`를 3자리로 계산하고 2자리로 찍어 관측치 **41%**가
  `-0.00%p`로 렌더됐다(`0.98 → 0.977` 재현 확인). usTreasury와 같이 2자리로 통일 →
  0이 되어 기존 필터에 자동으로 숨는다. `-0` 정규화 + 자릿수 계약 테스트 박제.
- 중간 3건 — BOJ 시각 미고지인데 `12:00` 단정(`timeKnown` 플래그로 생략) /
  BOJ 장애가 미국 지표 캐시까지 30분→2분으로 깎던 것 / aria-label이 수치를 삼키던 것.

### 5. BOJ 공식 API v1 전환 (PR #39, `1966e1b`)

- 기존 경로는 BOJ가 **"예고 없이 변경·삭제 가능"이라 명시한** 화면 다운로드 URL(168KB 전량).
  문서화된 유일한 기계 접근 경로인 API v1로 전환(8KB).
- **파서를 새로 쓴 이유**: NAME 필드가 따옴표 안에 쉼표 2개를 포함해
  단순 `split(',')`이면 8컬럼이 10개로 밀린다 → **끝에서부터** 날짜·값을 읽는다.
  결측 표기도 다르다(API `null` / 화면 CSV `NA`). `STATUS`≠200이면 throw.
- **의무 크레딧**(api_notice.pdf §2 원문 확인)을 카드 하단 출처에 지정 원문으로 표기(파운더 결정).
  번역 대체 시 '지정 문구 표시'가 아니게 될 수 있어 원문 + 한국어 병기.
- API도 §3에 따라 멈출 수 있어 기존 경로를 폴백으로 유지.
