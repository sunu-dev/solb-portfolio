## 작업 요약
- 사용자는 개인 주식비서다운 대화, 빈약한 선택 UI 개선, 이미 읽은 시간 안내 반복 제거를 요청했다.
- 운영 CAv 정본에서18파일만 선별해 AC5로 배포·승격. 정본 `/private/tmp/joobi-conversation-20261105`, 루트 전체 배포 금지.
- 시간순 대화·하단 입력·접힌 맥락·기간/시장 선택 버튼·동의·대기/중단·초안/포커스 보존 구현.
- 계정 Provider에 같은 탭 종목/시장/기간별20개 대화와 초안 저장. 요청은 이전3개만, 로그아웃·새로고침·탭 닫기 삭제. 진행 중 로그아웃은 요청도 중단.
- 읽은 시간 안내는 ‘확인했어요’ 후 다시 보기로 접고 launcher 반복 강조도 중단. 공개 안내 ID만 브라우저에 저장하며 다음 변경은 별도 ID로 노출.
- 후속 재설명 의도 분리, 의미 축소 방지, 자료 없는 회사 사업 추정 방지 프롬프트 보강. MU/하나마이크론 부분 일치 결함 수정.
- 로컬2183통과/9제외, 원격2180통과/12제외, 타입/선택ESLint/빌드 통과. 실제 Haiku4개 응답 원문 검토. 공급자 QA를 로그인 E2E로 표현하지 않음.
- Chrome MU 현재 종목/초안 재진입 확인. 최종 UI 추가 검수는 host unavailable/창 전환 충돌로 미완료.

- 운영 정적 파일72개와 새 코드/디자인 표시 확인. 보호된 후보의 비인증 정적 요청은 성공 검증으로 세지 않음.

## 결정사항
- 문서·캐릭터만 개선으로 세지 않고 실제 공통 화면·동작에 적용. `docs/JOOBI_CHAT_DESIGN_SYSTEM.md`에 실제 토큰/배치/상태 규칙 기록.
- 대화 기억은 현재 탭 범위. 장기 기억이나 보유수량 개인화가 완성됐다고 말하지 않음.
- 안내는 노출만으로 읽었다고 추정하지 않고 사용자 ‘확인했어요’로 처리. 새 변경은 다시 알림.
- 자동 테스트, Chrome 관찰, 실제 공급자 응답, 사용성 실측은 별도 근거로 관리. 미측정 만족도나 개선율을 만들지 않음.
- 초기 제한 네트워크 QA에서 MU 사업 자료가 빠졌으나 네트워크 허용 재시험에는 자료 제공. 운영 DB 장애라고 단정하지 않음.
- API 키·실제 사용자 대화는 기록하지 않음. 영구 메모리 승급은 별도 사용자 동의가 없어 하지 않음.
