# 2026-09-21 - 개인 포트폴리오 사각형 히트맵

## 작업 요약
- 원형 보완안도 반려됨. 사용자가 제공한 Finviz 히트맵 이미지를 기준으로 분석 탭의 내 포트폴리오 맵을 교체.
- 다크 차콜 프레임, 붙어 있는 직사각형 칸, 얇은 경계, 흰 종목명/등락률, 초록 상승·빨강 하락 및 7단계 범례 구현.
- 한국·미국 주식과 ETF를 함께 배치. 기존 평가금액 환산/동일 티커 합산을 유지하고 업종 및 ETF 상품 유형으로 그룹화.
- 저장된 종목명과 정규화한 코드의 한글 이름 조회를 보완. `005930`→삼성전자, `036540`→SFA반도체, 미등록 종목은 저장된 이름을 유지.
- 종목명이 긴 국내 주식은 칸에 맞춰 줄이고, 아주 작은 칸은 전체 종목 목록으로 선택. 비중을 과장하기 위해 작은 칸을 확대하지 않음.
- 기본 모드는 오늘 등락률. 누적 수익률 전환 시 배치 유지. 종목 선택·상세·키보드·공유 동작 유지.
- PC 실제 분석 그리드에서 맵만 전체 너비를 사용하도록 설정. 나머지 위젯 내용과 종목 탭은 수정하지 않음.
- 로컬 혼합 예시 31종목 추가. 실제 고객 보유 데이터나 현재 시세가 아닌 디자인 검증용 예시임.

## 결정사항
- 새 추상적 디자인 대신 사용자의 구체적인 참조 이미지에 맞춤. 종목명이 아닌 비중을 거대한 숫자로 보여주던 방식 제거.
- 칸 크기는 평가금액 기준, 색과 숫자는 선택한 기간의 수익률. 색 범위는 오늘 ±3%, 누적 ±30%; 범위 밖의 실제 수익률 숫자는 그대로 표시.
- 기존 업종/상품 분류 재사용. 확인된 국내 ETF 12개와 TSLL/MUU/KORU는 로컬 KIS 마스터의 이름으로 보완. 미확인 분류를 임의로 만들어 넣지 않고 미분류로 남김.
- 섹터 그룹의 총 면적을 평가금액에 맞추고, 제목을 제외한 동일 그룹 내 종목 비율 유지. 안내 문구에 제목 영역을 설명.
- 큰 검색 카탈로그 전체를 클라이언트 번들로 가져오지 않음.
- 새 SVG `<title>`의 여러 React 자식이 React 19 SSR hydration 오류를 일으킴. 단일 문자열로 수정한 뒤 오류 0 확인.
- 사용자가 사각형 히트맵 디자인을 확정하고 푸시 요청. 맵 코드·테스트·개발용 미리보기·이 기록만 `todo-final`에 커밋하는 범위로 확정. 운영 배포는 `main` 브랜치 연결이며 이번 작업은 운영 배포를 포함하지 않음.
