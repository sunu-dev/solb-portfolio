# 2026-10-02 - 뽐뿌 증권포럼 소개글과 화면 캡처

## 작업 요약
- 사용자 요청: 아내의 최근 주식 입문을 계기로 만든 초보자용 주식비서라는 개인적인 이야기를 담아 제목·본문 작성. 서버·AI 비용 때문에 소수 초대코드 이용으로 안내. 증권포럼 분위기 조사와 실제 화면 캡처 준비.
- 제품 설명 원칙과 실제 베타·샘플 체험 기능을 확인한 뒤 `artifacts/ppomppu-20261002/게시글.txt`에 복사할 수 있는 초안 작성.
- 사진 첨부 순서·설명과 조사 근거는 같은 폴더의 `사진설명과-게시안내.txt`에 저장.
- 검색에 노출된 2026-09-06 기업 분석 사이트 소개와 2026-03-22 배당 캘린더 소개·댓글 확인. 만든 계기, 실제 화면, 구체적인 기능과 개선 의견을 제시하는 방향으로 작성.
- 공식 전체 이용규칙 확인: 광고 글·사진 금지 명시. 비슷한 소개 사례만으로 이번 서비스 소개·초대 모집의 허용을 보장할 수 없음을 사용자에게 알림. 증권포럼 목록·일부 게시글 직접 접근은 403이므로 검색에 노출된 사례로 범위를 한정.
- CUA 캡처 도구가 `failed to write kernel assets: No such file or directory`로 실패. 세션 reset 후 getState도 동일 실패.
- 대체 기술 사용에 대한 UI 도구 규칙에 따라 Playwright 사용을 비동기 질문으로 요청. 이 기록 시점에는 사용자 답변이 없어 실행하지 않음. 실제 스크린샷은 아직 없음.

## 결정사항
- 과장된 성과·투자 후기·수익 보장을 넣지 않고, 작성자가 직접 만든 서비스라는 점과 무료 베타·소수 초대 이유를 공개.
- 사진은 실제 운영 화면으로 준비하며 체험용 샘플 표시를 유지. 개인 계좌·개인정보·초대코드를 노출하지 않음.
- 추천 첨부 순서는 리포트 → 발표 설명/금리 해설 → 샘플 내 주식. 랜딩 문구보다 초보자가 이해에 도움받는 실제 화면을 우선.
- 글 직접 게시·쪽지 발송·앱 코드 변경·배포는 하지 않음.
- 영구 메모리 후보 없음. 이번 자료와 캡처 도구 장애는 작업 기록으로 유지.
