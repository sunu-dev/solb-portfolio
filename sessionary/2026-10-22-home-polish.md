# 2026-10-22 - 홈 브랜드 디자인 업그레이드

## 작업 요약
사용자가 화이트·차콜·옐로, 기업 로고, 이미지와 배치의 대비를 적용하는 방향을 승인했다. 앞선 홈 구조 정리 위에 크림색 등록 영역, 실제 기업 로고5개, 짙은 리포트 진입, 그림이 있는 투자 이야기와 짧은 인터랙션을 구현했다. 의미 색과 일반 동작은 유지하고 홈에 공통 accentButton을 사용했다.

타입·ESLint·UI·다크 검사 통과, 기존 테스트6개 통과. Next QA 라우트200과 실제 컴포넌트 SSR/로컬 로고를 확인했다. 전체 한국어 검사는 기존 다른 시안 파일5건으로 실패했다. 브라우저 도구 연결 오류가 계속돼 실제 클릭·반응형·다크 화면 검수는 미완료다. 임시 QA 라우트 제거와 dev 서버 종료, 운영 배포 미실행.

## 결정사항
- 브랜드 강조 색과 표면을 공통 토큰으로 정의해 테마별 값이 흩어지지 않게 한다.
- 기업 식별에는 로컬 원본 SVG를 사용한다. 장식용 그림은 기존 주비 자산을 재사용하며 가짜 수치/차트를 만들지 않는다.
- 등록은 주요 행동, 기업 목록은 탐색, 리포트는 시장 진입으로 화면상 역할을 구별한다.
- 움직임 줄이기에서 hover/active의 CSS 우선순위도 확인해 실제 변환을 끈다.
- 구현 기준은 docs/UI_SYSTEM.md에 반영했다. 별도 일반 취향 규칙의 메모리 승급은 하지 않았다.
