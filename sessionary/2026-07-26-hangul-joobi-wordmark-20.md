# 2026-07-26 - 한글 주비 워드마크 폰트 20안

## 작업 요약

영문 `JOOBI` 방향을 잠시 두고, 전체 문장 `나만의 주식비서` 안에서 `주·비`만 크게 보여 멀리서는 두 글자 `주비`로 읽히는 한글 워드마크 20안을 `/brand-preview/hangul-20`에 구현했다.

## 결정사항

- 다섯 글자 묶음은 `나만의 / 주 / 식 / 비 / 서` 순서로 한 줄에 둔다.
- 모든 글자는 CSS 기준선으로 아래 정렬한다.
- `주·비`만 크게 하고 `나만의·식·서`는 작게 유지해 전체 문장과 두 글자 브랜드를 동시에 읽게 한다.
- 비교 공정성을 위해 카드의 배치·간격·크기·색은 고정하고 실제 한글 글씨체만 20종으로 바꾼다.
- 비교 글꼴은 Google Fonts 공식 저장소의 SIL OFL 글꼴만 사용한다.
- 각 글꼴의 원본 TTF와 `OFL.txt`를 함께 보관한다.
- 최종 글꼴이 결정되기 전까지 실제 앱 헤더는 변경하지 않는다.

## 검증

- Next.js 16.2.1 전체 사전 린트, TypeScript, 프로덕션 빌드 통과
- `/brand-preview/hangul-20` 정적 경로 생성 및 로컬 HTTP 200 확인
- 화면 응답에서 서로 다른 글꼴명 20개 확인
- 원본 TTF 20개와 개별 `OFL.txt` 20개 확인
- `git diff --check` 통과
