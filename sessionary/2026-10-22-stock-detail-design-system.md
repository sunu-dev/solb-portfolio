# 2026-10-22 - 상세 하단 디자인·로컬 디자인 작업실

## 작업 요약
사용자가 운영 상세의 최근 소식·자료·배경 개념·투자 연결 영역 캡처를 주고 개선을 요청하며 디자인 사이트 여부를 물었다. 별도 공개 사이트는 없고 문서·시안만 있었다고 알렸다. 상세의 반복 제목·안내문 위계를 정리하고 공통 색·글자·그림·실제 UI를 모은 로컬 디자인 작업실을 만들었다.

미지원 거래일 브리핑을 한 줄 펼치기로, 최근 소식은 날짜/빈 상태/다음 확인 사항으로 분리했다. 자료·브라우저 비교 안내를 한 펼치기로 모았다. 추가 자료는 가벼운 아이콘 목록, 개념은 크림색 질문에서 시작, 계산은 제목과 설명의 진입으로 바꿨다. 개념 목록 복귀와 초점 복원도 추가했다.

TypeScript·UI·다크 검사 통과, ESLint 오류0(기존 effect경고3). 기존 관련24tests 통과. 한국어 검사 기존 다른 로딩 시안5건 실패는 유지하며 이번 파일 위반은 없다. Chrome 실제 삼성전자 상세·390/320px·다크와 디자인 작업실의 빈/오류/질문·자료 왕복·초점 복원·계산 진입을 확인했다. 테마·임시 화면 크기 복구. 이번 변경은 로컬 반영이며 운영 미배포다.

## 결정사항
- 확인된 사실/누락과 배경 설명의 구분을 유지하고 안내를 필요한 위치에 접었다. 실제 데이터가 없는 영역을 채워진 것처럼 꾸미지 않았다.
- 별도 정적 시안 대신 공통 CSS와 실제 상세 컴포넌트를 작업실에 사용해 기준·화면 차이를 줄였다. 가상 예시를 명시하고 서비스의 영구 설정을 바꾸지 않는다.
- 사용자 요청을 별도 공개 디자인 도메인 등록·운영 배포로 확대하지 않았다. 원본 전체 배포 금지 원칙 유지.
- 구현 기준은 docs/UI_SYSTEM.md에 반영했다. 영구 사용자 선호를 새로 추정해 auto-memory에 저장하지 않았다.
