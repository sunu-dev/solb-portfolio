# 2026-10-22 - 계정 삭제 설정 이동

## 작업 요약
사용자가 프로필 메뉴의 계정 삭제 빨간 테두리 원인·확인창 유무를 문의하고 설정 안으로 이동을 요청했다. 상시 경고 버튼 테두리였음을 확인했다. 삭제 UI와 기존 두 단계 확인 핸들러를 설정 하단의 로그인 전용 계정 섹션으로 이동했다. 진입 버튼은 빨간 글씨만 표시하며 개인정보처리방침 경로도 수정했다.

타입 검사 통과, 변경 파일 ESLint 오류 0(기존 경고 4), 관련 기존 테스트 7개 통과. 로컬 Chrome에서 메뉴·설정 계정 섹션·첫 확인창을 확인했다. 기본 confirm 제어 도중 브라우저 자동화가 시간 초과되어 취소·두 번째 확인창 UI 검수는 미완료. 실제 삭제는 실행하지 않았다. 임시 QA 라우트 제거, dev 서버 종료. 운영 배포 미실행.

## 결정사항
- 삭제는 설정 안에서 찾도록 하며 프로필 메뉴에서는 제거한다. 삭제 진입에 상자형 강조를 사용하지 않는다.
- 기존 확인 두 단계를 유지해 실수로 삭제되는 것을 방지한다.
- 다른 경고 버튼에 영향을 주지 않도록 공통 dangerButton은 수정하지 않는다.
- 원본 전체 배포는 기존 변경이 섞이므로 금지한다.
