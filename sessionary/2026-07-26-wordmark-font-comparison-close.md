# 2026-07-26 - JOOBI 워드마크 폰트 비교 세션 종료

## 작업 요약

14번 기반 JOOBI 락업의 위치·크기 알고리즘을 유지하면서 `JOO BI` 자체에 서로 다른 실제 폰트 30종을 적용한 비교 화면을 최종 확인하고 세션을 종료했다.

## 결정사항

- 비교의 핵심 변수는 카드 장식이 아니라 실제 영문 워드마크 폰트다.
- 왼쪽 아이콘, 한 줄 `JOO BI`, 아래 `나만의 주식 비서`, `JOO↔주식`·`BI↔비서` 대응 구조는 고정한다.
- 폰트 30종은 프로젝트 내부에서 제공해 시스템 대체 폰트로 잘못 표시되지 않게 한다.
- 앱의 실제 헤더에는 아직 최종안을 적용하지 않는다. 후보 선정과 실사용 크기 검증을 먼저 한다.

## 검증

- 폰트 30개 선언과 시안 30개 매핑 일치
- 신규 대표 폰트 파일 HTTP 200 확인
- 전체 사전 린트, TypeScript, Next.js 16.2.1 프로덕션 빌드 통과
