# 2026-11-04 - 주비 질문 화면을 대화 형태로 변경

## 작업 요약
- 사용자 스크린샷의 질문 화면이 입력 양식처럼 보인다는 지적과 챗봇/마스코트 제안을 반영했다.
- `frontend-design` 스킬과 제품 원칙, 로컬 Next.js use-client 가이드를 읽고 기존 Pretendard·흰색/회색 읽기 화면·붉은 브랜드 포인트를 유지했다. 빨간 말풍선 얼굴만 장식 요소로 두고 배경 효과/과한 반복 모션을 피했다.
- `LearningDesk`에 채팅 전용 헤더/테두리, `JoobiAvatar` 벡터 캐릭터, `JoobiChat.module.css` 추가. 사전 화면은 기존 구조 유지.
- `AskJoobi`는 선택 종목 안내→질문 예시→내 질문/주비 답변→하단 입력창 순서로 변경. 종목/시장/기간은 접힌 대화 설정에서 변경한다. 기본 설정도 접힌 줄에 표시한다.
- 최신 답변을 과거 기록과 본문에 중복 표시하던 구조 제거. 각 답변의 근거·비교·출처는 펼치기로 보존. 질문 중 점 3개 애니메이션, reduced-motion 대응. 새 답변 위치로 이동하며 안정적인 turnId로 이전 펼침 상태의 잘못된 재사용 방지.
- 명시적 동의 체크, 전송 정보 상세, 로그인/횟수 제한, 용어 사전 연결, 후속 질문 입력창 채우기, 요청 취소/초기화 유지.

## 결정사항
- **로컬 구현 초안이며 운영 배포하지 않았다.** 최신 운영은 HUE 그대로다.
- 캐릭터는 대화 상대를 표시하는 작은 말풍선 얼굴이다. 브랜드 전체 마스코트 최종 확정이나 3D 이미지 제작은 아니다.
- UI 클릭을 위한 CUA 재연결도 browser host unavailable/native pipe startup failed. 다른 도구로 우회하지 않았으며 스크린샷 검수/실제 모바일/다크 시각 검수는 미완료다.
- 앱 src 범위 타입 검사, 선택 컴포넌트 ESLint, 공통 disclosure 검사/다크 토큰 검사 통과. 관련 기존 검사 79통과/3제외. 기존 API 회귀 검사는 UI 클릭 검증을 대신하지 않는다.
- 루트 전체 타입 검사는 기존 artifacts 원본 복사본의 MarketWatch publication 누락으로 실패. 전체 한국어 lint는 이번 수정과 무관한 brand-preview/loading 페이지 5건 실패. 해당 파일들을 임의 수정하지 않았다.
- 새 영속 제품 원칙 변경은 없으므로 auto-memory에 중복 승급하지 않는다.
