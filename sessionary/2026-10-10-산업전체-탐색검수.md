## 작업 요약
- 사용자: 반도체 예시를 다른 산업에도 공통 적용하고, 모든 섹터에서 대장주 한 개씩 골라 같은 방식으로 검수 요청. 작업 중 모든 산업을 분류하는지 재확인.
- 주요 산업 11개 + 세부 분야 9개 = 20개 분류. 정보기술·통신/미디어·경기소비재·필수소비재·에너지·금융·헬스케어·산업재·소재·부동산·전력/유틸리티와 반도체·광소재/광통신·의약/바이오·반도체 소부장·방산·항공/우주·조선·배터리·자동차.
- `sectorExploration.ts`: 산업·상위 산업·대표 기업·사업 역할·공식 출처·질문·확인 항목·전달 과정·연결 산업 등록. 새로 확인한 기업 28개, 기존 7개 포함 총 35개. 기존 11개 + 신규 57개 = 총 68개 설명.
- 공식 사이트 본문을 직접 읽고 사업 설명만 사용. 일부 이전 URL은 404·403·홈페이지 리디렉션이어서 유효한 실제 사업 소개 주소를 다시 확인. 삼성SDI는 `/business/index.html`에서 자동차·ESS 사업 확인. 추출 텍스트·실패/성공 흔적은 artifacts에 보존.
- 공통 UI: 산업별 제목·대표 기업·도해·질문·산업 간 이동·전체 산업 목록. 복수 사업 기업은 분야를 선택해 읽을 수 있음. 일반 대장주 설명에서 반도체 단정 제거.
- 미등록 종목은 기존 fundamentals의 sector/industry를 매핑하고 제공된 업종 기준임을 표시. 미확인 업종은 임의 분류하지 않고 산업 목록 제공. 확인 기업의 사업 역할을 공급자 분류보다 우선.
- 새 종목의 한국어 이름이 상단에도 표시되도록 검증된 기업명 fallback 보완. 기존 포트폴리오 저장 종목명 우선 유지.

## 결정사항
- 대표 기업 선정 기준을 비동기로 질문했으나 회신이 없었음. 사업 대표성을 기준으로 선정한다고 알리고 진행. 시가총액·점유율·수익률 1위라고 표시하지 않음.
- 큰 산업 분류 전체를 커버하는 것과 모든 상장사·세부 산업을 조사하는 것은 구분. 사용자에게 11대 산업+9개 세부 분야의 실제 범위와 미확인 종목 처리를 명시.
- 전 산업 설명의 출발점과 다음 질문을 제공하되 당일 주가 원인·최근 계약·최신 순위는 만들어내지 않음. 새 API 공급자·DB·AI 요청·분석 횟수 차감 없음.
- 기존 반도체 화면을 포함한 앞선 로컬 변경, 기존 문서·세션 기록 유지. 커밋·푸시·배포하지 않음.
