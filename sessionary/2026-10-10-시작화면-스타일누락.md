# 2026-10-10 - 시작 화면 스타일 누락

## 작업 요약
- 사용자가 iPhone Safari에서 큰 검은 로고와 '로그인 상태와 내 정보를 확인하고 있어요.' 문구가 표시된 사진을 전달.
- 문구는 `src/app/page.tsx`의 인증/로컬 기록 소유자 준비 경계와 일치.
- `JoobiLockup` SVG는 CSS에만 크기를 의존하고 width/height 속성이 없어 스타일 누락 시 화면 폭으로 확대됨. 시작 화면 배치도 Tailwind에 의존.
- 격리 Chrome 390px에서 운영 페이지의 CSS·JavaScript를 차단하니 동일한 형태로 재현됨(SVG 374×374px).
- `JoobiLockup.tsx`: SVG width/height 기본값 40px, loading 변형에 최소 inline 배치·글꼴 크기 지정. 정상 스타일은 기존 SVG 크기 규칙을 사용.
- `page.tsx`: 첫 화면 배치·색상·문구 크기를 inline으로 보강. native details 도움말 및 GET form으로 JS 없이도 문서를 다시 요청. 저장 실패 상태에서는 도움말을 펼쳐 표시.
- 계정 확인/복구본 보존 경계 및 기존 인증·DB 처리 변경 없음.

## 결정사항
- 네트워크 파일을 아직 못 받은 시점에도 첫 화면은 읽고 복구할 수 있어야 하므로 최소 스타일을 초기 HTML에 포함.
- 반복 자동 새로고침이나 로컬 저장 데이터 삭제를 하지 않고 사용자가 명시적으로 다시 불러오게 함.
- CSS/JS 차단 시 증상 재현은 확인했으나 실제 iPhone에서 누락이 생긴 원인은 미확정. 서비스 워커는 /_next/를 가로채지 않지만 페이지 HTML을 오프라인 fallback으로 보관하므로 오래된 HTML 가능성은 조사 대상으로만 남김. 추정만으로 SW 정책 변경하지 않음.
- 운영 HTML HEAD는 HTTP 200. 운영 자산 전체의 정상 로딩 또는 과거 장애의 원인을 증명하는 결과는 아님.
