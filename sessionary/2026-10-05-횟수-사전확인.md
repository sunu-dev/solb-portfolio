## 결정사항
- 사전 조회는 사용자가 선택하기 전 알려주는 용도이며, 최종 허용은 POST 서버에서 다시 판단.
- 클라이언트 조회 실패·로그인 필요·서비스 전체 한도를 개인 횟수 소진으로 해석하지 않음.
- 계정별 기본 분석 한도는 코드 기본값 3회이고 현재 free/pro 동일. 실제 수치는 서버 환경설정과 계정 정보를 통해 전달받음.
- 사용자 개인 Gemini 키 우선 사용 아이디어에는 ‘선택하는 고급 옵션, 개인 키 사용은 주비 제공 횟수와 분리, 오류 때 자동 대체 대신 선택, 키 암호화 보관·삭제’ 방향을 권고. 아직 구현 요청 확정·개인 키 기능 추가는 아님.
- Google 공식 과금 문서 확인: 개인 API 키의 프로젝트에 연결된 API 한도/과금 적용. https://ai.google.dev/gemini-api/docs/billing/ 와 키 보안 문서 https://ai.google.dev/gemini-api/docs/api-key 참고.
- 기존 원칙을 적용한 버그 수정으로 신규 영구 메모리 승급 후보 없음.
