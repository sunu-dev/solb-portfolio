# 2026-10-22 - 홈 빈 화면 디자인 수정

## 작업 요약
사용자가 큰 인사말·기업 목록·기본 개념 질문이 길게 펼쳐진 홈을 보고 AI 템플릿 같다고 지적했다. 검색·기업 탐색·등록의 역할을 나누고 제목과 여백을 줄였다. 기업마다 짧은 사업 설명을 추가하고 기본 개념은 3개 주제 선택 후 기존 본문을 읽도록 바꿨다. 브리핑 진입·리포트·예시 체험·보유 데이터 동작은 유지했다.

타입 검사·공통 UI 검사 통과, 기존 테스트 6개 통과. Next dev SSR 200 및 내용 확인. 브라우저 연결은 Native pipe 시작 오류로 사용 불가여서 실제 클릭·반응형·다크 화면 검수 미완료. 실제 렌더 결과 기반 정적 HTML 시안과 이번 변경 patch를 artifacts/home-design-20261022에 저장했다. 임시 QA 라우트 제거 및 dev 서버 종료. 운영 배포하지 않았다.

## 결정사항
- 큰 감성 카피보다 검색과 실제 이용 동작을 먼저 알아볼 수 있도록 한다.
- 시세가 없는 자리에는 가짜 수치나 그래프를 만들지 않고 확인된 사업 정보를 사용한다.
- 본문 전체를 홈에 펼치지 않고 선택 후 읽도록 하되 기존 설명·출처·산업 탐색을 유지한다.
- 사용자에게 토스형/매거진형/주비 그림형 방향을 질문했으나 아직 응답 없음. 공통 UI 기준에 맞는 간결한 방향으로 먼저 구현했다.
- 별도의 영구 디자인 규칙은 확정하지 않았다.
