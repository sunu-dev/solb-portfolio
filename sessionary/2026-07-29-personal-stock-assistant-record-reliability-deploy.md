# 2026-07-29 - 개인 주식비서 재정렬·기록 신뢰성·운영 배포

## 작업 요약

- 주비의 1차 정체성을 `개인 주식비서`로 두고 홈 순서를 오늘의 브리핑 → 자산 현황 → 핵심 기능 → 기록 관리로 재조정했다.
- 기록 관리는 기본 접힌 선택 기능으로 내리고, 동기화 실패·충돌·저장공간 위험이 있을 때만 상단 경고를 노출하도록 했다.
- 한국·미국 혼합 포트폴리오의 원화/달러 계산을 공통 통화 계층으로 통합하고, 좁은 화면에서 큰 금액이 두 줄로 밀리는 문제를 보완했다.
- 포트폴리오 변경 즉시 사용자별 로컬 outbox에 기록하고, 서버 CAS 충돌을 조용히 덮어쓰지 않도록 변경했다.
- 충돌 시 클라우드 최신본 또는 이 기기 변경을 명시적으로 선택하며, 로컬을 선택해도 기존 클라우드 종목을 복구 지점으로 보존하도록 했다.
- 보유 종목·일일 스냅샷·가져오기 복구 이력을 포함하는 JSON v2 백업/복원을 구현했다.
- 장기 스냅샷은 최근 1년 일별, 5년까지 주별, 이후 월별로 기간 제한 없이 보존하도록 계층 압축했다.
- 포트폴리오 저장 RPC v2에 명시적 사용자 ID 검증을 추가하고 운영 Supabase에 적용했다.
- 개인 주식비서 중심으로 랜딩·온보딩·메뉴·투어·OG 문구를 정리했다.
- 검증 후보를 거쳐 Vercel 운영 배포를 완료했다.
- 미사용 Gaegu 복사본과 확정이 끝난 한글 20종 비교 화면·글꼴을 제거했다. `public/fonts`는 약 78MB에서 1MB로 줄었고 Single Day 원본과 OFL 라이선스는 보존했다.
- 전역 Vercel CLI를 58.0.0으로 업데이트했다.

- 메모리로 이동됨: `project_product_identity.md` — 주비는 오늘의 종목·자산·손익을 챙기는 개인 주식비서다.
- 메모리로 이동됨: `project_record_operations_strategy.md` — 기록관리는 선택형 신뢰 인프라이며, 조용한 덮어쓰기 금지·명시적 충돌 해결·휴대 가능한 백업·계층형 장기 보존을 계약으로 삼는다.
