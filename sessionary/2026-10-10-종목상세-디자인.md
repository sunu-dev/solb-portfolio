# 2026-10-10 - 종목 상세 디자인과 포커스 정리

## 작업 요약
- 사용자 Typesafe 화면 참고 요청 및 보조 버튼의 두꺼운 파란 테두리 피드백 반영.
- 종목 상세에 흰색/회색과 차콜 다크 테마, 얇은 구분선, 절제된 모서리와 여백 적용. 가격·차트 제목·기간 선택·주비 노트·질문·배우기 스타일 정돈.
- 첫 포커스를 ‘넓게 보기’ 버튼에서 종목 제목으로 이동. 포인터로 너비 버튼을 누르면 포커스를 해제하고 키보드 조작은 유지. 공통 focus-visible 기본값을 중립색으로 지정.
- 넓은 화면에서 가격은 상단, 차트와 나머지 정보를 두 열로 묶어 뉴스 제목과 본문 사이의 큰 빈 공간 해결.
- 차트 캔버스가 패널의 실제 CSS 색상 변수를 읽도록 조정.

## 결정사항
- 앞으로 적용할 화면 강조·포커스 기준은 `docs/JOOBI_EXPLANATION_PRINCIPLES.md`에 기록. 보조 조작이 본문보다 과하게 강조되지 않도록 함.
- 키보드 사용자가 위치를 알 수 있도록 얇은 중립색 포커스는 유지. 최초 자동 포커스와 마우스 클릭의 불필요한 테두리는 제거.
- 전체 화면을 일괄 재설계한 것은 아니며, 종목 상세와 공통 포커스 기본값이 이번 범위.

- TypeScript, `git diff --check`, 운영 빌드 및 필수 prebuild 통과. 테스트 1,301 통과 / 선택형 1 skip. 기존 lint 경고 유지.
