# 2026-10-23 - 필요한 기능을 유지하는 I/O 개선

## 작업 요약
- 사용자 승인으로 기능 유지와 불필요 부하 제거를 구현했다. 변동 없는 종목 last_seen 쓰기를 제거하고 기본키 커서 조회, 일부 시장 수집 실패 시 오상폐 방지, 실패 쓰기 응답과 비용 측정 로그를 추가했다.
- 매분 digest scheduler가 실제 처리/정리/실패 보고가 필요할 때만 worker를 호출하는 SQL migration을 추가했다.
- 전체 1,723 tests 통과/2 skip, 임시 PostgreSQL에서 1,152개 scheduler/worker 상태 조합 일치. 앱 소스 타입 검사 통과, 기본 tsc는 기존 artifacts 백업 오류로 실패했다. 검증 근거와 적용 순서는 `docs/IO_PERFORMANCE_FIX_2026-10-23.md`.
- 검증 후 운영 DB 재조회도 로그인 역할 생성 단계 544/connection timeout으로 실패했다. 운영 DB 적용과 I/O 전후 실측은 대기 상태다.

## 결정사항
- 신규/상폐 감지와 매분 retry 주기는 유지한다. 빈 작업의 HTTP/RPC 비용과 기능상 필요하지 않은 행 갱신만 줄인다.
- I/O 경고의 주원인은 아직 실측되지 않았다. 로컬에서 제거한 쓰기 수를 운영 IOPS 개선율로 과장하지 않는다.
- 다른 작업의 미커밋 변경이 많으므로 운영 적용은 이번 변경 선별 및 개별 SQL 적용으로 진행한다.
