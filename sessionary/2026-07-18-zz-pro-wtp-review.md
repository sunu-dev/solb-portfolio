# 2026-07-18 - 무료·유료 정책 승급과 PRO 지불의향 심층 검토

## 작업 요약

도구형 PRO 원칙을 프로젝트 영구 메모리로 승급하고, 무료/유료 경계와 실제 지불의향 검증안을 새 문서로 정리했다.

- 무료/PRO 투자정보·AI 동일 원칙을 영구 메모리와 관련 법률·세무 문서에 동기화
- 기본 다중 증권사 통합·기본 동기화·기본 CSV/JSON 수동 내보내기를 영구 무료 기준으로 명시
- PRO 내보내기를 기간 묶음·변경 이력·예약 실행을 포함한 고급 내보내기로 재정의
- 과거 PRO AI 30회·무제한 가설이 남은 역사 문서에 폐기 안내 추가
- 실제 결제 가능성이 높은 기능을 자동 백업/버전 복구, 변경 이력, 여러 파일 OCR/중복 확인, 장기 기록/월간 기록 묶음으로 재정렬
- Sharesight, Snowball Analytics, TradingView, Portseido, Simply Wall St의 공식 공개 기능·가격 구조 비교
- 월 4,900원 단위 경제 시나리오와 문제 인터뷰, 가격 표시 가짜 문, 20명 실제 유료 베타, 가격 실험 순서를 설계
- 적격 사용자 판별과 가짜 문·유료 베타 GO/수정/중단 기준을 `proDemandValidation.ts` 순수 함수와 테스트로 고정
- 수요 이벤트에 종목·수량·평단·자산금액을 넣지 않는 최소 수집 원칙 명시

검증 결과 전체 테스트 149개 통과·1개 스킵, TypeScript, 변경 파일 ESLint, diff check, 프로덕션 빌드가 통과했다.

## 결정사항

- 월 4,900원·연 49,000원은 확정 가격이 아니라 실제 결제와 유지 전까지 내부 가설이다.
- 첫 실제 유료 베타는 월 4,900원 단일 요금제만 사용하고 연간 요금제는 2개월차 유지 확인 뒤 도입한다.
- 기본 데이터 내보내기를 유료로 잠그지 않는다. 사용자의 데이터 이동권을 결제 장치로 사용하지 않는다.
- PRO의 핵심 결제 이유는 기능 개수가 아니라 반복 정리 시간 절약과 기록 손실·실수 위험 절감이다.
- 첫 PRO MVP 권장 조합은 자동 백업/버전 복구 + 여러 파일 OCR/중복 확인이며, 월간 가치 영수증을 포함한다.
- 광고 제거와 화면 프리셋은 보조 혜택이며 핵심 결제 동기로 보지 않는다.
- 설문 의향은 결제를 입증하지 않는다. 가격 표시 시작 클릭, 실제 결제, 45일 유지, 두 번째 월 결제가 강한 증거다.
- 법률·사업·약관·결제·복구 게이트 전에는 실제 돈을 받지 않는다.
