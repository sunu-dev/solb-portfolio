# 2026-07-21 - JOOBI 위치 시안 5종

## 작업 요약

사용자 손그림이 폰트 지시가 아니라 `JOO`, `BI`, `나만의`, `주식`, `비서`의 위치 관계를 설명한 것임을 반영했다. `/brand-preview`에 14번의 Lexend 인상을 기준으로 한 51~55번 위치 시안 5개를 추가했다.

## 결정사항

- 영문은 다섯 시안 모두 대문자 `JOO`, `BI`를 사용한다.
- 새 폰트는 추가하지 않고 14번과 동일한 자체 호스팅 Lexend를 사용한다.
- 51은 손그림 대응 관계를 정돈한 구조, 52는 양끝 분리, 53은 세로 인덱스, 54는 크기 대비, 55는 의미 연결선 구조다.
- 기존 1~50안은 보존하고 비교 화면만 총 55안으로 확장한다.

## 검증

- 전체 사전 린트, TypeScript, Next.js 16.2.1 프로덕션 빌드 통과
- `http://localhost:3002/brand-preview`에서 55안 제목과 마지막 위치 시안 응답 확인
