# 2026-10-04 - 뽐뿌 증권포럼 소개 자료 캡처 완료

## 작업 요약
- 10월 2일 작성한 소개글의 후속. 사용자는 유사 소개글이 게시되고 있으니 현재 작성 방향을 유지하라고 확인.
- CUA의 커널 자산 오류가 반복되어 앞서 제시한 대체 Playwright 방식과 실행 승인을 통해 캡처 진행. Playwright Core는 `/private/tmp/joobi-ppomppu-capture-20261002`에만 설치해 프로젝트 의존성을 변경하지 않음.
- 독립된 headless Chrome 세션으로 실제 `https://joobi.kr` 공개 화면과 샘플 체험을 조작. 로그인·개인 계좌·기존 브라우저 프로필을 사용하지 않음.
- 리포트, 경제 발표의 영향 설명, 샘플 보유 종목, 금리 해설 4장 저장. 캡처 결과를 이미지로 열어 글자·구성·샘플 표시 확인.
- 초기 로딩 표시가 남은 리포트와 투어 후 스크롤 위치가 어긋난 샘플 화면을 다시 캡처. 최종 샘플 화면에는 체험 모드 안내와 3개 샘플 종목이 보임.
- 게시글의 샘플 설명을 보유 종목 화면에 한정하도록 정정. 경제 발표 화면의 수치까지 모두 가상 데이터라는 오해를 방지.
- 게시글·사진 설명·PNG 4장을 `주비-뽐뿌-게시자료.zip`으로 제공. 포럼 조사 근거는 별도 파일에 보존.

## 결정사항
- 게시 자료는 실제 운영 화면으로 구성. 샘플의 수익률을 작성자의 투자 성과로 소개하지 않음.
- 사진 순서는 리포트 → 경제 발표 연결 설명 → 샘플 보유 종목. 금리 해설은 선택적인 네 번째 사진으로 제공.
- 사용자가 수용한 포럼 규칙 안내를 반복하거나 추가 승인 절차를 요구하지 않음. 실제 게시·쪽지 발송은 수행하지 않음.
- 앱 코드·배포·Git 브랜치를 변경하지 않음. 캡처 검수는 게시용 화면 범위이며 실기기 전체 UI 검수의 완료를 뜻하지 않음.
- 영구 메모리 후보 없음. 기존 제품 원칙과 중복되는 내용을 별도 승급하지 않음.
