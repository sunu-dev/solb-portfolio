# 2026-10-22 - 홈 손그림 일러스트

## 작업 요약
사용자가 홈 디자인은 마음에 들며 그림만 손글씨 일러스트로 바꾸는 방향을 제안했다. 현재 UI는 유지하고 그림만 차콜 펜선·옐로 채색으로 변경했다. 등록·환율·금리·기업 비교4종을 내장 이미지 도구로 생성/변환해 홈 전용 새 파일로 저장했다. 기존 PNG와 다른 화면의 그림은 보존했다.

타입/ESLint·기존 테스트6개 통과. 로컬 QA 렌더200과 원본 크기/알파 확인. 정적 시안 갱신. 브라우저 도구 연결 문제로 실제 화면 검수는 미완료, 운영 미배포.

## 결정사항
- '그림만' 요청에 맞춰 CSS·배치·문구·버튼·로고를 유지한다.
- 원화·달러의 코드 그림도 같은 선 질감의 이미지로 교체해 네 장의 스타일을 맞춘다.
- 공유 원본은 덮어쓰지 않고 public/illustrations/home의 별도 파일을 사용한다.
- 이미지 생성은 내장 도구를 사용하고 프롬프트·산출물 경로를 보고서에 남긴다.
- 선호를 서비스 전체의 영구 일러스트 규칙으로 확대하지 않았다. 별도 메모리 승급 후보 없음.
