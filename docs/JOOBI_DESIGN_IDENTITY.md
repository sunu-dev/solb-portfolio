# 주비 디자인 아이덴티티와 검수

주비의 정체성은 초보자를 위한 주식비서다. 세상의 변화와 내 투자 사이를 이해하도록 돕는다. 제품·설명 판단은 JOOBI_EXPLANATION_PRINCIPLES.md, 기본 UI는 UI_SYSTEM.md를 따른다. 이 문서는 승인된 방향과 구현 위치, 예외와 미확인 범위를 연결한다.

## 유지할 성격

- 차분함: 확인된 숫자와 사실이 먼저다. 긴급함·수익 기대를 장식으로 만들지 않는다.
- 다정함: 쉬운 문장과 편안한 여백을 쓴다. 펜 드로잉은 이해를 돕는 자리에서 사용한다.
- 연결: 사건 → 중간 전달 과정 → 기업 → 내 투자로 이어가며 돌아오는 길을 보존한다.

토스·로빈후드는 사용성 비교의 참고다. 브랜드의 외형·거래 기능을 그대로 이식하는 기준은 아니다.

## 시각 요소의 역할

| 요소 | 역할 | 구현·예외 |
| --- | --- | --- |
| 붉은 심볼 + 주비 글자 | 서비스 식별 | JoobiLockup을 재사용한다. 글꼴·비율·간격·테마 변형을 유지한다. |
| 흰색·차콜 | 숫자와 읽기 | globals.css의 표면·본문 토큰 |
| 버터 옐로 | 중요한 시작과 선택 | brand-highlight/text-on-highlight 색쌍. 투자 추천·안전 표시로 쓰지 않는다. |
| 크림 | 질문과 학습의 초대 | surface-warm. 보조 자료를 모두 크림 카드로 만들지 않는다. |
| 빨강·파랑 | 한국 표기 관례의 상승·하락 | +·−/단위를 함께 쓴다. 장식 색과 분리한다. 작은 글자의 대비는 별도 점검한다. |
| 평면 펜 드로잉 | 개념 이해 | 승인한 홈4종. 밝은 종이 영역에서 선을 보존한다. |
| 기업 로고 | 기업 식별 | CompanyMark의 원본·출처를 쓴다. 펜 그림으로 바꾸지 않는다. |
| 선 아이콘 | 동작과 분류 | 현재 Lucide 사용. 이모지·색·상자를 같은 보조 영역에 중복하지 않는다. |

로고는 기존 header/modal/hero 변형을 사용한다. 임의 최소 크기나 보호 공간 수치를 새 확정 규격으로 선언하지 않는다. 실제 사용 크기·원본 코드와 검수를 우선한다.

## 읽기·배치·행동

기본 글꼴·일반 제목/본문/동작 크기는 globals.css와 AppUI/ReadingUI가 관리한다. 상세 도입의24–26px 제목은 DetailReading·AnalysisPanel에 있는 문맥별 표현이며 일반 그룹 제목을 모두 그 크기로 만들지 않는다. 작업실에서 모든 제목을 하나의 수치로 설명하지 않는다.

관련 요소8–12px, 묶음16–24px, 읽기 장32–40px를 기준으로 관계를 표현한다. 컨트롤은 기본48px, 아이콘44px를 유지한다. 모바일은 글자를 작게 만들기보다 배치를 바꾸고 긴 회사명·수치·기기 키보드를 확인한다.

기사 제목·본문 요약·AI 해석·일반 개념·실제 원인을 구분한다. 빈 자료는 평온함의 증거가 아니며 실패·지연·미지원과 구분한다. 저장 위치·로그아웃/계정 전환·삭제 취소를 확인한다.

상세 질문은 먼저3개를 목록으로 제공하고 추가 질문은 선택적으로 펼친다. AI 답변과 무료 배경 개념을 별도 동작으로 구분한다. 로그인·횟수·소진 상태는 명시하되 질문을 밀어내는 큰 상자를 사용하지 않는다. 받은 답변과 추가 목록에서 선택한 답변은 목록을 접어도 접근할 수 있어야 한다.

동작 반응은 보통150–180ms이며 reduced-motion에서 생략한다. 설명 그림·로고의 기존 단발/주기 모션은 별도 역할이고 정지 상태에서도 의미가 남아야 한다.

## 검수와 변경 관리

디자인 작업실 `/design` (기존 `/brand-preview/design-system`도 유지)은 실서비스 컴포넌트와 CSS를 직접 사용한다. 디자인 참고 내용과 화면별 적용 현황은 해당 경로의 designReference.ts, 실제 점검 도구는 DesignChecks.tsx에 있다.

현재 테마의 전경/바탕 색을 읽어 대비를 계산한다. 보통 본문 기준4.5:1을 참고하며 큰 글자·비활성·장식의 판정과 전체 화면 검수는 별도다. 상승·하락 기본색의 작은 본문 사용은 밝기·다크 테마 모두에서 재검토 대상이 될 수 있다. 이를 숨기거나 전역 의미 색을 임의로 변경하지 않는다.

기준은 [W3C 글자 대비](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)와 [초점 표시](https://www.w3.org/WAI/WCAG22/Understanding/focus-visible.html)를 참고했다. 키보드 초점은 제거하지 않고 포인터와 focus-visible을 구분한다.

변경 순서: 제품 원칙 확인 → 공통 역할 결정 → 실제 코드 반영 → 두 테마·상태·반응형·키보드 검수 → 적용 범위 갱신. 수동 체크리스트는 작업 중 직접 확인한 항목만 표시한다. 서비스 전체 완성도나 인증 점수로 쓰지 않는다.

## 현재 예외·남은 범위

- 승인한 펜 드로잉은 홈4종이다. 기존97개 산업 그림의 스타일 전체 교체와 혼합 표현은 별도 검토 범위다.
- 기존 부가 화면·관리자·법적 안내의 개별 스타일, 인라인 색과 문구를 전수 검수한 상태는 아니다.
- Chrome320/390px 검수와 실제 Safari/PWA·삼성 브라우저·큰 글자·OS 움직임 줄이기는 구분한다.
- 실제 OAuth·계정 삭제 확인 취소·가져오기 오류·두 기기 저장은 기존 후속과 함께 확인한다.
- 작업실과 상세 후속의 운영 적용 여부는 배포 기록에 남긴다. 작업실은 joobi.kr/design에 함께 제공하며 독립 도메인은 사용하지 않는다.
