- [ ] 시장 관찰판이 개인별 추천처럼 표시되지 않는다.

- [ ] 관찰판 카드에 바로 종목 분석으로 이동하는 버튼이 없다.
- [ ] 목표 수익률은 사용자 설정값과 현재 달성률만 보여주고 보유·매도 행동을 제안하지 않는다.
- [ ] 사용자 설정 하락 기준은 현재가와의 차이·도달 여부만 보여준다.
- [ ] AI 분석 결론은 `정보 정리`와 중립 신호로 표시된다.
- [ ] 투자자 유형을 바꿔도 관찰 목록과 종목 결론은 달라지지 않고 설명 방식만 달라진다.
- [ ] Free와 PRO의 AI 분석·시장 관찰판 일일 한도가 같다.

## 5. 월 예산 하드캡

기본값은 비활성이다. 로컬 검증 시에만 `.env.local`에 아래 값을 임시 설정한다.

```dotenv
AI_MONTHLY_BUDGET_USD=0.01
AI_MONTHLY_BUDGET_STOP_RATIO=0.95
```

- [ ] 환경변수가 없거나 `0`이면 기존 AI 호출에 영향이 없다.
- [ ] 관리자 화면에 월 사용액/예산/사용률이 표시된다.
- [x] 설정 예산의 95% 미만에서는 새 AI 호출이 허용된다.
- [x] 95% 이상에서는 AI 분석이 `budgetLimited=true`로 차단된다.
- [ ] 95% 이상에서 AI 촉은 최근 24시간 캐시를 우선 반환한다.
- [ ] 캐시가 없으면 사용자에게 점검/월 한도 안내가 표시된다.
- [ ] 예산 가드 활성 상태에서 원장 조회 실패 시 새 유료 호출이 발생하지 않는다.
- [x] 임시 환경변수는 로컬 실행 프로세스에만 설정되고 `.env.local`을 변경하지 않는다.
- [ ] 이번 달 누적 비용과 월말 예상 비용이 표시된다.
- [ ] 예산 설정 및 월 호출 데이터가 있을 때 예상 잔여 호출 횟수가 표시된다.
- [ ] 예산 또는 호출 데이터가 없으면 임의의 숫자 대신 `계산 대기`로 표시된다.

## 6. AI 출력 감사

두 번째 마이그레이션 `20260716000200_ai_output_audits.sql`을 로컬 검증 DB에 적용한 뒤, 로컬 환경에서만 표본율을 설정한다.

```dotenv
AI_AUDIT_SAMPLE_RATE=1
```

- [ ] 관리자 화면에 `AI 감사` 탭이 보인다.
- [ ] AI 분석과 AI 촉이 각각 목표 100건 대비 수집률로 표시된다.
- [ ] 표본율이 0이면 `표본 수집 중지` 안내가 표시된다.
- [ ] 심각도 필터를 바꿔도 상단 전체 합계와 기능별 준비도는 변하지 않는다.
- [x] `검토 자료 JSON 저장` API로 관리자 전용 익명 검토 묶음이 생성된다.
- [x] 저장된 JSON에 사용자 식별자·프롬프트·평단·보유수량·목표수익률·손절값·사용자 메모가 없다.
- [x] AI 분석 또는 AI 촉 호출 후 익명 표본이 저장된다.
- [x] 사용자 ID·보유수량·평단·사용자 메모·프롬프트가 저장되지 않는다.
- [x] 종목 AI 분석은 공개 종목 코드만 함께 표시된다.
- [ ] 금지 표현은 `high`, 목표가·매매 방향은 `review`로 분류된다.
- [ ] 출력 보기로 최종 사용자 노출 JSON을 확인할 수 있다.
- [ ] 출력 보기를 펼치면 공개 데이터 기준값과 AI 출력이 좌우로 표시된다.
- [x] AI 분석 기준값에 시세·등락률·기술지표·PER/EPS·52주 범위만 들어간다.
- [x] AI 촉 기준값에 공개 시세·변동률·PER·52주 위치만 들어간다.
- [x] 기준값에 보유수량·평단·목표·손절·사용자 메모가 들어가지 않는다.
- [ ] AI가 언급한 수치와 공개 기준값을 사람이 대조할 수 있다.
- [x] 검토 완료 API 호출 후 `reviewed_at`이 기록된다.
- [ ] 전체·높음·검토·정상 필터가 작동한다.
- [ ] 시험 후 `AI_AUDIT_SAMPLE_RATE`를 제거하거나 `0`으로 되돌린다.

- [ ] `AI_AUDIT_SAMPLE_RATE=1` 로컬 시험 중에는 표본율 확인 경고가 표시된다.
