# 산업별 Anatomy 그림

사용자 요청: 2026-10-15. 기존 산업 그림을 Anatomy로 교체하고, 빠진 업종 그림도 점검한다.

## 범위

- 산업·사업 분야의 기준 목록은 `SECTORS` 42개다. 42개 모두 서로 다른 구조의 전용 장면을 제공한다.
- 나라별 자료 제공처의 업종은 `INDUSTRY_GROUPS` 303개다. 각 ID와 원문 이름을 명시적으로 장면에 연결한다. 상위 산업 그림으로 자동 대체하지 않는다.
- 303개에 고유 그림 303장을 만들었다는 의미는 아니다. 비슷한 활동은 장면을 공유한다. 전체 97개 장면 정의, 85개 고유 기하 구조이며, 같은 구조에도 설명이 다른 장면이 있다. 그림과 회사별 사업 근거·설명의 공급 범위는 서로 다르다.
- 새 업종이 생기거나 원문 이름이 바뀌면 생성기와 커버리지 검사가 실패한다. 연결이 없는 새 업종을 기존 그림으로 조용히 덮지 않는다.
- 양자컴퓨팅/양자내성 보안, 원자로 개발/핵연료/발전 운영, 연료전지/배터리, 반도체/소부장은 별도 장면이다. 모기지 리츠/건물 임대, 시설 경비/사이버보안, 해운/조선도 설명을 구분한다.

## 그림의 성격

- [Anatomy 스킬](https://github.com/wheresryan22/anatomy/blob/main/SKILL.md)의 Figure 규모로 제작했다. 원본 기하 도구를 사용하며 부품·받침·체결·면의 음영과 깊이 순서를 기록한다. 각 그림은 최소 40개 부품을 갖는다.
- 산업을 이해하는 대표 장면이다. 특정 기업의 실제 설계·고객 설치·공정 수치·엔지니어링 시뮬레이션으로 표시하지 않는다.
- 금융·암호 등 추상적인 주제는 업무 공간이나 비유를 쓴다. 표현 방식과 한계는 생성 자료에 기록한다. 양자컴퓨팅의 예시는 모든 구현 방식의 공통 설계가 아니다.
- 현재 제공물은 정지 SVG다. 원본 스킬의 회전·분해·물리 시뮬레이션·WebGL을 모든 그림에 제공한다고 표현하지 않는다. 움직임 없이도 내용을 읽을 수 있고 동작 줄이기 설정에 영향을 주지 않는다.
- 그림 아래에는 산업을 설명하는 한 줄만 둔다. 사용자 요청(2026-10-15)에 따라 ‘그림에서 무엇을 보나요?’ 구성 설명은 화면에서 제거했다. 내부 탐색의 기존 같은 창 동작을 유지한다.

## 구현·갱신

- 제작 도구: `scripts/vendor/anatomy/` — MIT 라이선스와 원본 아카이브 해시 보존. 앱에서 실행하지 않는다.
- 원본 장면·실제 부품 목록: `scripts/sector-art/{objects,scenes}.mjs`.
- 업종 연결: `scripts/sector-art/catalog.json` — 정확한 업종 ID/원문 → 장면.
- 생성: `node scripts/generate-sector-illustrations.mjs --audit`.
- 산출: `public/illustrations/sectors/*-{light,dark}.svg`, `src/data/sector-illustrations.json`.
- 화면: `SectorIllustration.tsx`와 `SectorIllustration.module.css`. 기존 일러스트 인라인 코드와 업종의 상위 산업 그림 대체 로직은 제거했다.
- 그림의 면·테두리·구조는 파일로 제공한다. 브라우저에 모든 SVG 코드나 제작 도구를 묶지 않으며, 사용자 조회가 이미지 생성·AI API를 호출하지 않는다.
- 밝음/어두움 파일을 주비의 `.dark` 테마에 맞게 전환한다. 외부 SVG 내부의 시스템 색상 설정에 의존하지 않는다.

## 검수

- `sectorArtwork.test.ts`는 현재 전체 분류와 생성 목록을 대조하고, 두 테마 파일·접근성 설명·스크립트 및 원격 자원 없음·혼동하기 쉬운 사업 구분을 검사한다.
- 기하·깊이·지지대 검사, Anatomy 원본 선 검사, SVG 경계 검사, 그림 모음과 확대 화면의 시각 검수, 실제 탐색 UI의 42+303개 진입과 반응형 검수를 수행한다.
- 검수 증거와 최종 결과는 `artifacts/anatomy-sectors-20261015/REPORT.md`를 따른다. 브라우저의 API/계정 자료는 격리 fixture이며 실계정·실기기·운영 배포 검증과 구분한다.
- 운영 반영 여부는 배포 기록에서 확인한다. 그림 변경과 공통 시장 관찰 기능의 배포 범위를 구분한다.

## 2026-10-15 형태 품질 보완

- 자동차는 원형 타이어·휠·경사진 차창, 방산은 오목한 접시형 레이더, 항공기는 둥근 동체·엔진·꼬리날개로 다시 제작했다. 우주 발사체는 길이 비례·보조 추진체·노즐, 위성은 태양전지판·접시형 통신 안테나를 보완했다. 항공 운송도 같은 개선 기체를 사용한다.
- 임의 축 회전체·입체 단면을 원본 Anatomy 도구로 만들고 같은 실제 형상을 기하 검사에 기록한다. 타이어·차창·태양전지판은 재질을 구분한다.
- 후속 검수는 `artifacts/sector-quality-20261015/`에 기록한다.
- 운영 배포는 그림 변경만 분리한다. 기존 계정은 Hobby로 확인돼 시장 관찰의 10분 cron을 지원하지 않는다. 요금제·DB·cron 변경은 이번 그림 배포에 포함하지 않는다.

- 서비스 워커는 `/illustrations/sectors/`를 cache-first로 고정하지 않는다. 같은 주소의 그림을 수정해도 HTTP 재검증으로 새 배포를 받는다.
