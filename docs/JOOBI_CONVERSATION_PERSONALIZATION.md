# 대화 기반 개인화·통계 설계안

상태: 2026-11-13 사용자 토글 예시를 바탕으로 작성. 기능/DB/운영 수집 미적용.

## 확인한 현재 구조
- 대화는 createConversationStore의 계정별 메모리에 최대20턴 유지. 영구 대화 기록 저장소가 아니므로 과거 전체 대화 분석을 약속할 수 없음.
- assistant_quality_events는 원문·계정·종목 없이 유형/결과/지연 집계.
- assistant_quality_cases는 사용자가 편집·제공 동의한 사례만30일 저장, 본인 삭제 지원.
- JOOBI_QUESTION_QUALITY_ENABLED 및 실제 DB 적용/운영 활성 상태는 이번에 미확인.

## 제안 화면
제목: 주비를 나에게 맞추기

[꺼짐] 대화로 맞춤 답변 받기
동의한 뒤 나눈 대화에서 설명 길이와 관심 주제 같은 선호를 기억해 답변에 활용해요. 기억한 내용은 직접 확인하고 수정하거나 지울 수 있어요.

[꺼짐] 주비 답변 품질 개선에 참여하기
동의한 뒤의 질문 유형과 답변 만족도 등을 분석해 주비를 개선해요. 대화 원문을 검토용으로 제공할 때는 내용을 먼저 확인하고 별도로 동의해요.

하단: 선택하지 않아도 기본 대화를 이용할 수 있어요. 설정에서 언제든 변경할 수 있어요.
원문 제공은 기존 사례 미리보기/개인정보 제거/30일 삭제 방식 유지. 실제 모델 학습을 하지 않으므로 모델 학습 문구 사용하지 않음.

## 구현안
- 동의 목적별 version/accepted_at/withdrawn_at 저장. 서버에서 매 요청 확인, 클라이언트 토글만 신뢰하지 않음.
- 개인화는 설명 길이/용어 풀이 선호/사용자가 확정한 관심 주제부터 시작. 보유종목·재산·투자성향을 대화에서 단정하거나 자동 프로필로 만들지 않음.
- 사용자가 확인한 구조화 선호만 저장. AI 추출 제안은 확정 전 다음 답변에 사용하지 않음. 원문 자동 영구 저장 없음.
- 끄면 즉시 읽기·쓰기 중단. 기억 지우기 별도 제공, 계정 삭제 시 함께 삭제. 동의 철회와 동시 진행 요청은 저장 직전에 재확인.
- 통계는 기존 원문 없는 품질 집계 재사용. 개인화 저장소를 관리자 사례 열람에 재사용하지 않음.
- 활성화 전 동의 API/계정 격리/철회 경합/삭제/만료/저장 실패 검증. 실제 데이터 활성화는 범위 확정 후 별도 단계.

## 미결정
- 개인화 선호 유지기간과 비활성 계정 정리기간.
- 기존 원문 없는 운영통계와 새 선택 동의 통계의 범위 구분.
- 초기 UI 위치(대화 설정 우선 제안), 동의 상세 문구 및 운영 반영 일정.
