# 주비 읽기 화면의 공통 디자인 기준

[앱 공통 UI 기준](UI_SYSTEM.md)을 바탕으로 읽기 화면의 역할을 정의한다.

기본 글꼴은 `globals.css`의 `--font-ui` 한 곳에서 관리한다. 본문, Tailwind `font-sans`, 버튼·입력의 상속 경로가 같은 글꼴을 사용한다. 로고와 고정폭 숫자·코드의 의도된 예외는 유지한다.

| 역할 | 기준 | 구현 |
| --- | --- | --- |
| 주요 섹션 제목 | 20px / 650 / 줄높이 1.5 | `--type-section-*`, `sectionTitle` |
| 펼치기·보조 동작 | 14px / 550 / 줄높이 1.6 | `ReadingUI.module.css`의 `disclosure`, `secondaryAction` |
| 읽기 본문 | 15px, 긴 글은 줄높이 1.75 이상 | `--type-body-size` |
| 날짜·출처·기록 설명 | 12px, 보조색 | `--type-caption-size` |

펼치기 제목은 안내·출처·디렉터리라도 같은 동작이므로 같은 글자 크기와 색을 쓴다. 펼친 뒤의 설명은 보조 정보로 구분한다. 공통 disclosure는 우측 화살표, 48px 이상 클릭 영역, 키보드 초점 표시를 포함하며 native details/summary 동작을 보존한다. 보조 버튼은 중립 표면과 실선 테두리를 사용한다. 상승·하락·위험 등 의미 있는 색은 기존 의미 토큰을 사용한다.

새 읽기 화면은 공통 모듈을 가져오고, 별도의 summary 타이포그래피나 브라우저 기본 삼각형·플러스 표시를 추가하지 않는다. 모바일에서 같은 역할의 글자를 별도로 축소하지 않는다. 시각적 위계는 역할과 여백으로 구분한다.

적용 범위: 종목 상세의 배우기, 뉴스 기록 안내, 기업·산업 설명, ETF 구조 설명, 차트/숫자/종합 분석 펼치기와 개인 도구 진입. 같은 펼치기 역할은 도움말·소개·포트폴리오·시장 안내·관리자에도 적용한다. 설정·로그인·온보딩 등의 기본 동작은 AppUI를 사용한다. 달력 사건·다중행 지표 카드는 명시된 복합 역할로 자체 정보 위계를 보존한다.


## 종목 상세의 읽기 리듬 (2026-10-17, 로컬 후속안 포함)
- 가격은 큰 숫자로, 주요 섹션은 20px 제목으로 구분한다. 기업·산업·ETF의 도입 제목은 24px(좁은 화면 22px)로 첫 설명을 강조한다.
- 데스크톱은 큰 그림 옆에 기업 요약과 첫 질문을 함께 보여준다. 모바일은 요약 → 큰 그림 → 질문 순서다. 기업 요약을 산업 분류보다 먼저 보여준다. 상세 사업 설명이 있는 기업만 고객·매출 구조 펼치기를 제공한다.
- 첫 질문은 해당 기업에 연결된 질문을 사용한다. 다음 두 질문에는 이어 읽을 이유를 붙이고, 추가 질문에는 개수와 첫 질문 제목을 미리 보여준다.
- 섹션 간 여백은 32~40px, 관련 질문 사이는 8~12px로 구분한다. 첫 질문만 중립 배경으로 강조한다.
- 종목 상세의 산업 그림은 최대 380px로 충분히 크게 배치한다. 본문 영역이 680px 이하이면 설명 아래에서 가용 너비를 사용하고 가운데 정렬한다. 97개 산업 그림과 303개 업종 매핑에 두 테마의 2~2.6초 단발 애니메이션을 적용한다. 화면 진입 시 한 번 재생하고 원본 정지 그림으로 복귀하며 다시 보기를 제공한다. 움직임 줄이기 설정에서는 정지 그림을 사용한다.


## 가독성 보완 (2026-10-17)
- 기업·산업 핵심 요약과 설명 본문은 모바일에서도16px/줄높이1.8, 기본 글자색으로 읽힌다. 관련 기업 설명15px, 원화 설명14px로 구분하고, 날짜·종목코드 등 보조 정보만 작은 보조색으로 남긴다.
- 기업·산업 도입 제목은28px, 좁은 화면25px. 핵심 본문을13px로 축소하지 않는다.
- 600px 이하의 읽기 영역에서 기업 목록은1열, 그림은최대300px. 데스크톱 기업 목록은2열을 유지한다.
- 이어지는 산업·주요 산업 목록·원본 업종 분류·전체 업종 디렉터리는 ‘다른 산업과 분류 살펴보기’에 모은다. 기본적으로 접고, native details/summary와 키보드 조작을 유지한다.
- 이번 선별 운영 소스는 `/private/tmp/joobi-reading-release-20261017`. 위 로컬 후속안 전체가 운영된 것은 아니다. 특히 원화 모션은 승인된5종만 운영 중이다. 상세 배포 기록은 `artifacts/detail-readability-20261017/REPORT.md`를 따른다.

## 종목 상세의 읽기 순서 (2026-10-17)
- 회사 한눈에 → 확인된 고객·수익 구조 → 최근 소식 → 확인할 지표 → 대표 질문 한 개를 기본 흐름으로 둔다.
- 산업 그림/관련 기업은 그 뒤 선택 탐색으로 연결하고, 돌아오면 읽던 설명을 복원한다.
- 회사 설명은 검증된 자료만 사용한다. 상세 자료가 없는 종목은 사업 요약과 미확인 범위를 표시하고, 업종명으로 수익 구조를 만들지 않는다.
- ETF는 기업 고객·매출 설명 대신 기존 상품 구조를 유지한다.

## 상세 공통 시각 역할 (2026-10-18)
회사 이해·투자 점검·후속 질문은 `DetailReading.module.css`의 제목·본문·보조 문구 역할을 공유한다. 제목은 데스크톱24px/650, 모바일22px. 각 영역에서 독자적인 로고·번호·세로선을 다시 만들지 않는다. 핵심 본문16px/1.8, 보조 펼치기48px 기준. 사업 구조 모션은 확인된 사실의 연결을 설명하고, 화면 진입1회·다시보기·움직임 줄이기를 지원한다. 장식용 무한 반복은 사용하지 않는다.

### 제목 일치 범위 보완 (2026-10-18)
최근 소식도 회사 소개·지표·후속 질문과 같은 `DetailReading.title`을 직접 사용한다. 제목 검수는 font-size뿐 아니라 font-weight/line-height/letter-spacing을 함께 비교한다. 홈 최초 진입은 검색과 기업 목록을 주 흐름으로, 리포트와 샘플 체험을 보조 흐름으로 배치한다.
