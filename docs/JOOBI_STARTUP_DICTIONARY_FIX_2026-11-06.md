## 첫 화면을 막던 경로
기존 로그인 진입은 세션 확인 → 설정·관리자 확인 → 초대 기록 → 이용 동의 조회 순서였다. 초대 확인 결과를 기다리는 동안 AgeEligibilityGate 자체가 마운트되지 않아 동의 조회도 뒤늦게 시작했다.

운영 검수 계정 첫 접속은 초대 확인 단계가 완료되지 않아 오류 화면이 됐다. 45초 관찰 종료 시 메인은 열리지 않았고, 그중 포트폴리오 요청은 약 11.3초에 응답했다. 설정·관리자 요청은 관찰 중 완료되지 않았다. 실제 사용자 계정 자료는 읽거나 변경하지 않았다.

두 번째 접속은 메인 표시까지 4.910초. 관리자 확인 3.378초 뒤 초대 기록 0.241초, 이어 이용 동의 0.283초를 기다렸다. 페이지 HTML 자체는 빠르게 도착했으므로 HTML 로딩과 계정 진입 대기를 구분한다.

### 변경
- 현재 세션의 계정과 조회 계정이 같은지 확인한 뒤 본인의 RLS 보호 초대 기록을 먼저 조회한다. 초대가 확인되면 설정·관리자 API를 기다리지 않는다.
- 기록이 없거나 조회 오류가 있으면 기존 공개 모드·서버 관리자 확인 경로를 유지한다. 조회 실패를 임의 허용으로 바꾸지 않는다.
- 초대 확인 중에도 동일한 AgeEligibilityGate를 마운트해 동의 조회를 병렬로 수행한다. 동의 저장 → 최신 버전 조회의 순서는 유지한다.
- 계정 경계, 미확인·오류 차단, 변경 계정 결과 격리는 유지한다. 로컬 허용 캐시를 추가하지 않았다.

## 사전
- 지연 로딩 도중 native dialog 바깥에 남던 포커스를 제목으로 옮겼다. dialog 외곽선만 제거하고 버튼·입력의 키보드 포커스는 유지했다.
- PC 설명 18px, 모바일 17px, 예시 16px. 최대 너비 1100px·높이 800px, 목록:설명 0.7:1.3. 1440px 화면에서 설명 카드 너비 612px 확인.
- 저장 단어가 없을 때 보이는 기본 4개와 전체 수록 범위를 구분하기 위해 ‘전체 58개 단어 보기’를 추가했다. 숫자는 실제 데이터 길이로 계산한다. 신규 용어 54개를 추가했다는 뜻이 아니다.
- 사용자가 ‘내용이 작다’고 한 뜻을 추가 질문했으나 답변이 없어, 읽는 크기와 전체 용어 발견성 모두 개선했다. 용어 본문 대량 증설 작업으로 보고하지 않는다.
