# 규칙 기반 알림 감사 기록

기준일: 2026-07-16

## 결과

- `npm run lint:alerts`: 통과, 금지 어휘 0건
- 알림 생성: LLM 미사용, 결정론적 규칙
- 인앱 카드 면책: `AlertCard`에서 강제 표시
- 토스트 면책: `ToastAlert`에서 강제 표시
- 푸시: 짧은 면책 문구를 발송 경로에서 첨부
- 사용자 푸시 동의: 기본 OFF
- 발송 증거: `alert_log`에 성공·실패·만료 결과 기록 설계

## 남은 법률 검토 항목

코드 검사를 통과했다는 사실은 해당 알림이 투자조언이 아니라는 법률 결론을 뜻하지 않는다. 특히 아래 표현·기능은 변호사 확인 전 별도 위험 항목으로 둔다.

- `buy-zone`: 사용자가 직접 입력한 가격이라도 이름이 신규 매수 시점을 암시할 수 있음
- 목표가·손절가 도달: 단순 사실 통지 범위를 넘는 후속 행동 문구가 붙지 않는지 확인 필요
- `수익 실현 검토 신호`: 보유자에게 매도 방향을 암시할 수 있음
- RSI 과매도·골든크로스 등: 객관 지표 설명과 매매 시사 사이의 문맥 확인 필요
- 개인별 우선순위 정렬: 같은 문구라도 사용자 보유정보로 선별·강조되면 개별성이 강해질 수 있음

## 운영 게이트

1. 변호사 검토 전 알림 제목·본문에 행동 동사를 새로 추가하지 않는다.
2. 금지어 검사는 모든 빌드에서 필수로 실행한다.
3. 알림 정책이나 템플릿 변경 시 이 감사 기록을 갱신한다.
4. 실제 푸시를 켜기 전 동의 화면, 알림 예시, 구독 해지 경로를 수동 확인한다.
