# 주비 무료 베타 AI 법률 검토 패키지

기준일: 2026-07-16  
목적: 자본시장법 전문 변호사의 서면 의견 요청용 사실관계와 질문 정리  
주의: 이 문서는 개발·운영 사실을 정리한 의뢰 자료이며 법률의견서가 아니다.

## 1. 요청하는 결론

아래 각 질문에 대해 `가능 / 조건부 가능 / 불가` 중 하나와 필요한 수정사항을 서면으로 요청한다.

1. 무료 베타의 현재 AI 종목 분석이 자본시장법상 투자자문업에 해당하는가?
2. 개인 보유 종목·평단·목표·손절·투자자 유형을 입력한 출력은 “개별성 있는 조언”으로 평가되는가?
3. AI 촉이 사용자의 보유종목과 섹터 편중을 반영해 관찰 후보 3개를 고르는 행위는 명칭·면책과 무관하게 투자판단 조언인가?
4. 서비스가 무료여도 광고수익, 제휴수익, 향후 유료 전환 목적이 자본시장법 제6조의 “이익을 얻을 목적” 판단에 포함되는가?
5. 투자정보 기능은 무료로 두고 저장공간·OCR 횟수·내보내기·광고 제거만 유료로 팔 경우, 그 유료대가와 투자정보 제공 사이의 실질적 관련성이 인정되는가?
6. 사용자 자신의 Gemini API 키를 연결하도록 하는 구조가 운영자의 투자자문업 또는 유사투자자문업 해당성 판단을 바꾸는가?
7. 규칙 기반 목표가·손절가 도달 알림은 사용자가 직접 정한 값을 단순 통지하는 범위에서 허용되는가? `buy-zone`, `수익 실현 검토 신호` 같은 현재 표현은 삭제해야 하는가?
8. 무료 베타 전에 투자자문업 등록, 유사투자자문업 신고 또는 금융위원회 법령해석이 필요한가?
9. 필요한 약관, 개인정보 처리 고지, AI 공급자 국외이전·처리위탁 고지와 사용자 동의 수준은 무엇인가?

## 2. 법령상 출발점

- 현행 자본시장법 제6조 제1항은 이익을 얻을 목적으로 계속적·반복적으로 하는 금융투자업에 투자자문업을 포함한다. [국가법령정보센터 제6조](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1024121429)
- 현행 제101조 제1항은 일정한 대가를 받고 통신물 등을 통해 금융투자상품의 투자판단 또는 가치에 관한 **개별성 없는 조언**을 업으로 하려는 경우 유사투자자문업 신고를 요구한다. [국가법령정보센터 제101조](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1017471463)
- 유사투자자문업자에게는 손실보전·이익보장 오인 광고와 사실과 다른 수익률 표시 등의 금지 규정이 있다. [국가법령정보센터 제101조의2](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1025096689)

따라서 “무료이므로 아무 신고가 필요 없다” 또는 “면책문구가 있으므로 투자조언이 아니다”라고 내부적으로 확정하지 않는다. 특히 개별성 있는 출력은 제101조의 개별성 없는 조언과 다른 쟁점이므로 제6조상 투자자문업 여부를 별도로 답변받는다.

## 3. 서비스와 수익 구조

- 서비스명: 주비(joobi), 개인의 주식 비서
- 형태: Next.js 기반 웹/PWA
- 사용자가 직접 포트폴리오를 입력하거나 증권사 화면을 OCR한다.
- 주비에서 주문·체결·증권계좌 연결·사용자 자금 운용은 하지 않는다.
- 1차 단계는 무료 초대 베타 50명이다.
- 검토 중 수익원은 광고, 광고 제거, 데이터 저장·내보내기·OCR 편의 기능 유료화다.
- 투자자문사 제휴 없이 단독 운영하는 안을 전제로 검토를 요청한다.
- 결제와 광고는 아직 운영 적용하지 않는다.

## 4. AI 기능별 사실관계

### AI 종목 분석

- 로그인 사용자 전용이다.
- 시장정보 외에 보유수량, 평균매수가, 현재 손익, 목표수익률, 손절가, 비중, 사용자 메모, 투자자 유형이 모델 입력에 들어갈 수 있다.
- 결과에는 현재 상태 해설, 위험, 상승·하락 시나리오, 결론 레이블이 포함된다.
- 매수·매도 직접 표현은 프롬프트, 후처리, 감사 규칙으로 제한한다.
- 단일종목 레버리지·인버스는 서버 후처리로 신규 방향성을 제거한다.

### AI 촉

- 사용자의 보유 종목을 후보에서 제외한다.
- 보유 비중, 신호, 메모 맥락, 섹터 집중도와 투자자 유형을 반영할 수 있다.
- 서로 다른 섹터의 종목 3개를 “관찰 후보”로 제시한다.
- 현재 구현은 사용자별·날짜·시장 구간 캐시를 사용하며 새 생성은 하루 1회로 제한한다.
- 이 기능은 명칭을 “정보”로 바꾸더라도 실질적으로 개인화된 종목 선별일 수 있다는 위험을 전제로 의견을 요청한다.

### 포트폴리오 OCR

- 사용자가 첨부한 증권 화면 이미지를 Gemini에 전달해 종목, 평단, 수량을 구조화한다.
- 원본 이미지는 주비 데이터베이스에 저장하지 않는다.
- 인식 결과를 사용자가 확인한 뒤 포트폴리오에 반영한다.

### 규칙 기반 알림

- LLM을 호출하지 않는다.
- 사용자가 정한 목표가·손절가, 보유 종목 가격과 기술지표를 결정론적 규칙으로 비교한다.
- 푸시는 기본 OFF이며 사용자의 명시적 동의 후 사용한다.
- 사용자 노출 카드·토스트·푸시에 정보 제공 목적의 면책을 붙인다.
- 매매 권유·수익 보장 금지어 정적 검사(`npm run lint:alerts`)가 빌드를 차단한다.

## 5. 개인정보·공급자 전달

- AI 분석과 AI 촉에는 개인화 포트폴리오 정보가 공급자 API 입력으로 전달될 수 있다.
- OCR에는 사용자가 올린 이미지가 전달된다.
- 비용 원장은 프롬프트·응답 원문·API 키를 저장하지 않고 기능, 모델, 토큰, 추정비용, 지연시간만 저장한다.
- 출력 감사 저장·내보내기는 사용자 식별자, 프롬프트, 평단, 보유수량, 목표수익률, 손절값, 사용자 메모를 제외한다.
- 운영 공급자 계정은 실제 사용자 데이터 처리 전에 유료 티어 사용 여부, 모델 개선 사용 여부, 보관기간, 처리지역, 국외이전·처리위탁 고지사항을 확인한다.

상세 흐름은 `docs/AI_DATA_FLOW_MAP.md`를 함께 제공한다.

## 6. 비용·사용량 통제

- 1차 베타 결정안: 50명, 전체 120 AI 호출/일, 월 $15, $14.25에서 자동 중단
- 회원별: 분석 3회/일, AI 촉 새 생성 1회/일, OCR 2회/일
- Claude 자동 폴백은 끈다.
- 모델 호출 전 월 예산과 전체·사용자별 일일 한도를 서버에서 검사한다.
- 실제 호출마다 비용 원장을 기록하고 기록 실패가 반복되면 회로를 연다.

상세 산식은 `docs/AI_FREE_BETA_OPERATING_PLAN.md`를 함께 제공한다.

## 7. 감사 증거

로컬 통합 검증에서 확인한 사항:

- 실제 Gemini AI 분석, AI 촉, OCR 호출 성공
- 모델·토큰·비용·지연시간 원장 저장
- AI 촉 캐시 조회 시 추가 비용 행 미생성
- 월 예산 95% 도달 시 모델 호출 전 503 차단
- 전체 일일 250회 도달 시 모델 호출 전 429 차단
- AI 출력의 공개 입력 기준값과 금지표현 플래그 저장
- 익명화 감사 JSON 내보내기와 관리자 검토 완료 처리
- 규칙 기반 알림 정적 금지어 검사 통과

현재 실제 AI 출력 감사 표본은 AI 분석 1건, AI 촉 1건이다. 기능별 100건 목표를 채우지 않았으므로 “안전성이 통계적으로 검증됐다”고 주장하지 않는다. 무료 베타 중 전수 기록하고, 기능별 100건 검토 전에는 유료화·광고 개인화·호출 한도 증설 결정을 하지 않는다.
