# 주비 제품 전략 — 이해를 돕는 개인 주식비서

작성일: 2026-10-02. 사용자 확정 방향과 현재 작업 트리 기준이다. 경쟁 우위와 시장 선도는 검증할 목표이며, 달성한 성과가 아니다.

## 제품의 중심

주비는 **주식 초보자가 자기 종목과 실제 시장 소식을 편하게 확인하고, 그 의미와 영향을 이해하도록 돕는 개인 주식비서**다. 중요한 소식을 찾고 필요한 설명을 읽는 일이 자연스럽게 이어져야 한다.

사용자가 든 『브라질에 비가 내리면 스타벅스 주식을 사라』는 글로벌 변화에서 경제·산업·기업을 거쳐 투자로 이어지는 탑다운 관점을 설명한 은유다. “친구에게 설명할 수 있다”는 말도 충분히 이해한 상태를 뜻한다. 제품에서는 실제 발표와 자기 종목을 중심에 두며, 책의 소재를 대표 콘텐츠로 삼거나 퀴즈·작문 과제를 요구하지 않는다.

사용자가 얻어야 할 결과는 세 가지다.

- **무엇이 달라졌는지 안다.** 내 종목의 변화와 확인된 발표 결과, 예정된 일정을 구분한다.
- **왜 중요한지 안다.** 낯선 용어의 뜻과 금리·환율·수요·비용을 거쳐 기업에 영향이 전달되는 과정을 이해한다.
- **무엇을 더 볼지 안다.** 기업별 차이, 시간차, 시장의 사전 기대를 살피고 다음 발표에서 확인할 점을 찾는다.

첫 타깃은 보유·관심 종목은 있지만 금리·물가·환율·실적 소식을 자기 투자와 연결하기 어려운 사용자다. 첫 화면은 **내 종목과 실제 발표 → 핵심 의미 → 필요한 배경 설명 → 다음에 확인할 내용** 순서로 구성한다. 메모는 원하는 사람이 남기는 보조 기능이다.

## 현재 구현과 다음 범위

| 영역 | 현재 작업 트리 | 후속 검증·개선 |
|---|---|---|
| 서비스 소개 | `/about`에서 실제 이용 방식과 설명용 예시, 초대 방식, FAQ 제공. `/landing`은 `/about`으로 이동 | 방문자가 원하는 정보를 바로 찾는지 관찰 |
| 리포트 | 실제 발표의 이전·이번 수치 → 기업별 점검 경로와 조건 → 다음 관련 일정 → 공식 출처. 아래 ‘더 알아보기’에 배경 설명 제공 | 실제 발표와 설명 사이의 연결 위치·정보 순서 개선 |
| 배경 설명 | 금리·물가·환율·실적 4개. 용어, 기업에 전해지는 과정, 고려할 조건, 확인할 점, 출처 포함 | 사건별 기준 시점·근거·갱신·정정 관리 강화 |
| 내 종목 | 보유·관심 종목 중 공식 사업 자료를 확인한 애플·테슬라·마이크로소프트·엔비디아·삼성전자에 주제별 점검 경로 제공. 미지원 연결은 미확인으로 표시, 샘플 제외 | 기업별 근거 갱신과 지원 범위 확대 |
| 관련 발표 | 지원하는 일정 유형의 최근 확인 결과와 다음 발표로 이동 | 지난 결과와 새 결과에서 무엇이 달라졌는지 쉽게 제시 |
| 선택 메모 | 메모 저장·다시 보기·복사. 같은 탭의 상위 메뉴·설명 왕복 시 초안 유지, 다른 탭의 저장 변경 충돌 안내 | 계정별 보관과 기기 간 이어 보기의 필요성 검증 |
| 행동 측정 | 현재 화면의 설명 열기와 메모 저장 이벤트 | 운영 집계와 사용자 조사로 실제 이해·유용성·재방문 확인 |

4개 설명은 편집한 배경 콘텐츠이며, 실시간 뉴스마다 자동으로 인과관계를 분석한 결과가 아니다. 기업별 점검 경로는 공식 사업 자료를 읽고 편집한 조건부 설명이며, 실제 사건의 수혜·피해를 자동 판정하거나 계좌를 분석한 결과가 아니다. 사업 자료의 기준 기간·확인일·출처를 표시한다. 직접 수혜·피해나 주가 방향이 확인된 것처럼 표현하지 않는다.

로그인한 사용자의 메모는 **현재 브라우저에만 저장하고 로그아웃·다른 계정 전환 때 지워진다.** 저장 전 초안은 같은 탭에서 다른 상위 메뉴를 다녀와도 유지되며 새로고침하면 사라진다. 비로그인 메모는 체험 중에만 유지되고 새로고침·로그인 시 지워짐을 버튼과 안내에서 구분한다. 보관할 글은 복사할 수 있다. 자동 저장이나 기기 간 동기화로 안내하지 않는다.

## 화면과 상호작용의 기본 품질

- 중요한 정보와 주된 행동을 먼저 보여준다. 많은 카드·슬로건·장식보다 실제 내용을 읽기 쉬운 순서로 놓는다.
- 중립 표면과 공통 색상 토큰을 쓰고, 강조색에는 의미를 부여한다. 밝은 화면과 다크모드를 함께 검수한다.
- 한국어 어절과 짧은 의미 단위를 살리고, 작은 화면에서 서술어만 따로 떨어지는 줄바꿈을 줄인다.
- 320·390·430px, 데스크톱, 큰 글자 환경에서 잘림·겹침을 확인한다. 터치 영역 44px 이상, 키보드 포커스, 화면 읽기 이름, 돌아왔을 때의 위치를 검수한다.
- 종목 없음과 연결 기준에 맞는 종목 없음, 결과 확인 중과 실제 결과, 메모 초안과 저장 완료를 구분한다.
- 실제 iPhone·Android에서 스크롤·키보드·입력·복귀·대기 시간을 확인한다. 화면 폭 검사만으로 실기기 성능 검증을 완료했다고 하지 않는다.

## 제품 밖의 사용자 조사로 이해도를 검증한다

아래는 **향후 검증 제안이며 완료한 조사나 성과가 아니다.** 제품에 시험·점수·숙제를 추가한다는 뜻도 아니다. 참여에 동의한 초보자를 대상으로 자연스러운 사용 과업을 관찰한다.

| 검증할 가치 | 조사 과업·지표 |
|---|---|
| 찾기 쉽다 | 원하는 실제 발표와 설명을 찾는 데 걸린 시간, 도움 없이 완료한 비율, 막힌 지점 |
| 이해된다 | 소식을 읽은 뒤 용어의 뜻·영향 경로·달라질 조건·내 투자에서 볼 점을 자연스럽게 설명하는지 관찰 |
| 잘못 확신하지 않는다 | 시장·통화 기준의 종목 표시를 직접 수혜·피해 확정으로 오해하지 않는지 확인 |
| 모바일에서 편하다 | 실제 종목·발표 확인과 선택 메모 사용 중 가림·입력 손실·포커스 이탈·가로 넘침 점검 |
| 다시 찾을 이유가 있다 | 첫 방문 후 7일 내 관련 발표를 다시 확인하는 비율과 다시 온 이유를 조사 |

초기에는 8–12명의 관찰로 큰 장애물을 찾고, 과업별 완료율과 이해 정도의 기준선을 수집한다. 소규모 관찰 결과를 시장 전체의 성과로 일반화하지 않는다. 토스증권과 비교할 때는 동일한 주제·과업을 사용하고 제시 순서와 기존 사용 경험을 기록한다. 화면의 인상뿐 아니라 필요한 정보에 도달했는지와 실제로 이해했는지를 함께 본다.

설명 열기나 메모 저장은 행동의 증거이며 이해의 정확성을 자동으로 증명하지 않는다. 설명 원문·종목 목록을 행동 이벤트의 메타데이터로 보내지 않는다. 브라우저 식별자 삭제·기기 변경·로그아웃이 재방문 집계에 미치는 영향과 운영 집계의 분모를 확인한 뒤 지표를 해석한다. 체류시간 증가도 혼란 때문에 발생할 수 있으므로 단독 성공 지표로 쓰지 않는다.

## 다음 우선순위

1. 실제 리포트·종목 확인·배경 설명·복귀 흐름과 모바일 기본 품질을 마무리한다.
2. 초보자 관찰에서 정보 순서와 설명이 막히는 지점을 수정한다.
3. 지원되는 실제 발표부터 사실·근거·기준 시점을 갖춘 해설과 다음 확인 사항을 강화한다.
4. 기업의 사업 구조에 관한 근거를 확보해 종목 연결을 정밀하게 만든다.
5. 반복 방문의 이유가 확인된 뒤 기록 보관·개인화 범위를 넓힌다.

주비의 경쟁력은 **초보자가 자기 주식과 시장을 가장 편하게 이해하도록 돕는 경험**으로 검증한다. 시장 1등이나 경쟁 우위는 그 결과가 쌓인 뒤 판단한다.
