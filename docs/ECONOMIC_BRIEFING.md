# 경제 일정과 브리핑

## 사용자 흐름
- 모든 지원 이벤트는 용어 뜻부터 설명한다. 상세는 영향 경로·생활 예시·달라질 조건을 제공하고 FOMC는 인상/인하/동결 예시를 선택할 수 있다. 공통 기준: `JOOBI_EXPLANATION_PRINCIPLES.md`.
- 주비 리포트 첫 화면: 최근 7일 내 확인된 발표 1건 → 이번 결과의 의미 → 내 종목 점검.
- `내 주식과 어떤 관련이 있나요?`에서 해당 발표 상세를 열면 일반적인 중요성·함께 볼 지표·출처를 확인한다. 실제 주가 움직임의 원인을 단정하지 않는다.
- 리포트/더보기의 `경제 일정`: 주간·월간·발표 결과, 경제지표·보유/관심 미국 종목 실적·휴장일 필터.
- 분석/성향/회고는 별도 `분석` 메뉴로 이동했다. 리포트는 발표 핵심·내 종목 점검·경제 일정만 제공한다.
- 하단은 내 주식 / 주비 리포트 / 분석 / 소식 / 더보기, 총 5개다. 분석 내부는 종목 찾기 / 내 투자 점검 / 기록 돌아보기. 도구를 선택할 때만 불러오고 기존 과거 비교는 기록 돌아보기에 포함한다.
- 로그인 브리핑과 재방문 시 새 결과 브리핑. 브라우저 localStorage의 계정별 키로 읽음 처리하며, 서버나 다른 기기와 동기화하지 않는다. 닫기/Escape/배경 클릭 시 표시한 최신 결과를 기록한다. 열린 세션에서 5분마다 팝업을 반복하지 않는다.

## 자료
- 일정: 연준 FOMC HTML, BLS ICS, BEA ICS, 한국은행 회의 목록. 마지막 검증 목록 `src/data/economic-schedule.json`으로 장애 시 보완한다.
- 결과: FRED DFEDTARL/DFEDTARU, CPIAUCNS, PCEPI, UNRATE/PAYEMS. 발표 대상 월과 정확히 일치해야 결과로 연결한다. 현재 시계열은 수정치가 포함될 수 있음을 표시한다.
- FOMC: 공식 결정문 링크가 있어야 발표 완료. 숫자는 발표일과 다음 날의 FRED 목표금리 비교이며 점도표/기자회견 요약을 자동 생성하지 않는다.
- 한국은행: 공식 결정문 공개 확인과 링크를 제공한다. 금리 수치 자동 추출은 미구현이다.
- 실적: 기존 Finnhub earnings/calendar. 실제 EPS가 있어야 결과. 0도 유효하다. 날짜/장 전후만 주어지는 경우 정확한 발표 시각으로 표시하지 않는다.
- 휴장일: 기존 프로젝트 휴장일 목록. 2026년 범위.
- 미국 시각의 서머타임을 반영해 한국시간으로 표시한다. 실적 일정은 미국 현지 날짜/장 전후를 함께 표기한다.

## 갱신과 한계
- `/api/economic-events`: 공개 자료, 종목 입력 최대 30개 검증, 개인 종목 응답 private/no-store.
- Next Data Cache: 일정 1시간, 결과/실적 15분. 클라이언트 5분 갱신 및 동시 요청 공유.
- 인증 cron `/api/cron/economic-events`: 매일 한국시간 06:45에 자료 확인. 실제 화면 요청도 자료를 갱신한다. 외부 푸시/메일은 발송하지 않는다.
- BLS ICS가 차단되는 경우 검증된 배포 목록을 사용하며 화면에 상태를 알린다. 공식 일정 변경/다음 연도 목록을 계속 점검해야 한다.
- 경제지표 시장 예상치는 현재 계정 권한에 없어 미제공. 국내 종목 실적 일정은 미연결. 임의 예상값이나 가짜 결과로 채우지 않는다.
- 발표 결과는 최근 120일의 조회 기반 목록으로, 최초 발표 당시 수치를 영구 보관하는 아카이브는 아니다.

## 미리보기·검증
- `http://localhost:3000/report-preview`: 실제 리포트 컴포넌트와 실제 API. development에서만 접근 가능, production에서는 404.
- 테스트: 경제 일정 파서, 서머타임, 지표 대상 월, 미래 결과 배제, EPS 0/누락, 읽음 중복 억제.
- Chromium 320/375/390/430px, 월 이동, 상세, 브리핑 재열기 및 Escape. 실제 iPhone Safari 별도 확인 필요.
