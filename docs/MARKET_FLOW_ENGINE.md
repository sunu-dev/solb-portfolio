# 시장 흐름 설명 엔진

## 제품 동작

사용자가 질문하지 않아도 내 투자와 주비 리포트의 시장 소식 위에 거래일별 브리핑을 표시한다. 순서는 `무슨 변화 → 시장 전체와 기업별 차이 → 확인된 배경과 전달 과정 → 내 기록과의 연결 → 다음 확인 항목`이다. 첫 화면은 짧게, 자세한 설명과 출처는 펼쳐 읽는다.

## 입력과 판단

- 기존 정기 수집과 공개 `market_watch_events`를 재사용한다. 한국 주요 지수 2개, 미국 주요 지수 2개, 미국 업종 ETF 11개, 별도 반도체 ETF, 환율·원자재·금리와 주요 미국 기업 8개를 관찰한다.
- 주요 기업은 INTC/NVDA/AMD/AMZN/GOOGL/MSFT/META/AAPL이다. 모든 상장 기업을 감시하는 기능은 아니다.
- 양대 지수가 같은 현지 거래일이고 시각 비교가 가능해야 브리핑을 만든다. 미래·비정상 수치·상충 중복·오래된 자료를 배제한다. 정규장 가격 필드만 사용하며 시간외 등락과 합산하지 않는다.
- 두 지수 모두 ±0.3%를 넘어 같은 방향이면 동반 상승/하락으로 분류한다. 주요 지수 절대 등락 1.5%, 성장주 지수 2% 이상은 큰 움직임으로 분류한다. 이는 편집상 선별 기준이지 수익 예측 확률이 아니다.
- 업종 분모는 조용한 관측까지 포함한 11개 ETF다. 큰 변화만 남긴 화면 목록으로 계산하지 않는다. SOXX는 XLK와 중복되므로 업종 분모에서 제외한다. 8개 미만이면 업종 전반으로 일반화하지 않는다.
- 기업 등락 절댓값 5% 이상 또는 대표 지수와 차이 4%포인트 이상을 별도 비교한다. 지수 대비 차이는 초과 등락이며 시장 원인·지수 기여도·베타 추정이 아니다.
- ETF 간 수익률 차이를 자금 유입/유출로 단정하지 않는다. 미국 ETF를 한국 업종의 시장 폭으로 사용하지 않는다.

## 설명의 근거와 자동화 경계

시세 비교와 중요 변화 선별은 자동이다. 경제 발표·실적의 수집된 사실과 관련 보도도 연결한다. 기사 제목은 원인 검증과 분리한다.

`marketFlowEvidence.ts`는 거래일과 공개 가능 시각을 지정한 **수동 검증 설명**이다. 현재 2026-10-30의 AI 설비투자/현금흐름, Intel 전망 2건을 회사 발표와 보도에 연결했다. 다른 거래일에 재사용하지 않는다. 이 2건을 자동 원인 추론이나 모든 미래 사건의 자동 설명으로 표현하면 안 된다.

확인된 설명이 없는 거래일에는 수치 비교를 제공하면서 배경 확인 중이라고 표시한다. 후속 확장은 공시 원문 수집, 수치·기간·단위 검증, 원문 근거 위치 보존, 반대 근거와 정정 이력, 다양한 과거 사건 재현 평가를 거친 뒤 자동 게시 범위를 넓힌다. 아직 검증되지 않은 생성형 설명은 운영 자동 게시하지 않는다.

## 개인정보와 비용

공개 API는 보유 종목·금액·계정 식별자를 받지 않는다. 공개 브리핑과 보유 종목의 일치는 기존 브라우저 상태에서 계산한다. 이 구현이 기존 포트폴리오의 서버 보관 방식을 암호화로 바꾸는 것은 아니다.

첫 시장 흐름 엔진 자체는 새 DB 테이블·AI 호출·이용자별 분석 저장을 추가하지 않았다. 후속 자동 설명 확장에는 공개자료 전용 private 저장소와 공유 모델 호출이 있으며 사용자별 분석 저장은 없다. 읽기 요청은 기존 공개 자료 조회와 순수 계산만 수행한다. 기존 수집기에 고정 기업 8개가 추가되며 이용자 수에 비례해 외부 시세를 요청하지 않는다. 푸시/이메일 발송은 이번 변경에 포함하지 않는다.

## 검증과 재현

- `python3 scripts/verify-market-flow-stage.py`: 검증된 운영 기준본에 선택 파일만 복사한 격리 검증. 타입·제품 검사·전체 테스트·선택 ESLint.
- `node scripts/replay-market-flow-engine.cjs`: 읽기 전용으로 확보한 공개 관측 재현. 계정/투자 기록 없음.
- `node scripts/verify-market-flow-ui.cjs`: 실제 Next 컴포넌트, 공개 자료 fixture, 320/390/1440px, 필터·키보드·출처·자료 부족·개인 기록 미전송 확인.
- 근거: `artifacts/market-flow-engine-20261031/`. 격리 테스트 성공을 운영 수집/사용자 인증 통합 성공으로 대신하지 않는다.

## 자동 설명 확장 설계

원문 수집·주장 검증·자동 게시/보류·정정·비용 예약·출시 평가의 구현 설계는 [시장 배경 자동 설명 엔진](MARKET_CAUSE_AUTOMATION_DESIGN.md)에 정리했다. 초기 설계 이후 SEC8기업의 비공개 생성·검수와 연준·한국은행 금리 발표의 자동 사실 검증·공개가 운영에 연결됐다. 전체 시장 원인 추론의 자동 공개는 아직 미완료다. 현재 범위와 근거는 위 문서16절 및 `artifacts/market-cause-expansion-20261031/REPORT.md`를 따른다.
