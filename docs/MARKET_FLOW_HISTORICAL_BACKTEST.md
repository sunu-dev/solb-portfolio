섹터 수치는 섹터 내 종목의 일간 등락률 중앙값이다. 순환 판정은 단순 격차뿐 아니라 강한 섹터의 상승 종목 비율 60% 이상, 약한 섹터의 상승 종목 비율 40% 이하를 함께 요구한다. 그래서 2025-04-09는 격차가 가장 컸지만 모든 비교 섹터가 상승해 순환으로 판정하지 않았다.

## 해석과 한계

- 서로 다른 성격의 다섯 거래일에서 의도한 강·약 섹터와 순환 여부를 재현했다.
- 2026-07-07의 강한 에너지 섹터는 표본이 2종목뿐이어서 신뢰도를 `보통`으로 낮춘 것이 적절했다.
- 이 결과는 종목 추천이나 향후 방향 예측이 아니라 당일 횡단면을 설명하는 검증이다.
- 현재 유니버스는 섹터별 표본 수가 2~9종목으로 고르지 않다. 따라서 화면에는 표본 수와 상승 종목 비율을 계속 함께 표시해야 한다.
- Yahoo 데이터는 테스트 재현용이다. 운영 사용 전에 데이터 라이선스와 상업적 표시 권한을 별도로 확인해야 한다.

## 재실행

```bash
npm run test:market-flow:history
```

날짜를 바꿀 때는 쉼표로 구분한다.

```bash
MARKET_FLOW_DATES=2025-01-27,2025-04-09 npm run test:market-flow:history
```

기본 테스트에서는 외부 네트워크를 호출하지 않으며 이 백테스트 파일은 건너뛴다. 위 명령을 명시적으로 실행할 때만 과거 종가를 내려받는다.
