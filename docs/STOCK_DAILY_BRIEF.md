# 종목별 최근 거래일 브리핑

2026-10-18 구현. 상세 순서: 가격 → 차트 → 거래일 브리핑 → 최근 소식 → 회사 이해 → 지표.

## 수집과 발행
- 미국 주요 18개 종목. `BRIEF_TARGETS`가 공개 지원 범위. 국내 종목·ETF·미등록 기업은 미지원 안내와 기존 뉴스 제공.
- Yahoo 일봉 최대 6개월에서 최근 두 거래일 등락, 과거 최대 60일 절대 등락률 상위 5% 비교. 40개 미만이면 평소 대비 판정 생략.
- 같은 미국 거래일인 S&P 500 및 업종 ETF만 비교. 동반 하락을 인과관계 또는 자금 이동으로 설명하지 않음.
- 기존 Gemini의 Google Search grounding 사용. 검색 쿼리·grounding supports·지원된 HTTPS sources가 모두 있어야 배경 게시. 웹의 지시를 따르지 않도록 프롬프트 설정. AI 검색 요약은 인과관계 확정이나 사람의 원문 검증과 다름.
- 검색 제안 HTML은 스크립트와 동일 출처 권한 없는 sandbox iframe으로 표시. 소스 링크와 검색 확인 날짜 제공.
- 수집은 인증된 cron만 실행. 공개 API는 저장 결과만 읽음. 사용자 보유/계정/개인 정보는 검색에 전달하지 않음.
- DB lease로 중복 실행 방지, 발행 시 소유권 확인, 오래된 시세가 새 시세를 덮지 않음. 시세 실패 시 기존 기록 유지, 같은 거래일의 배경 갱신 실패도 기존 설명 보존.
- 가격 수집 동시 5개, 검색 동시 3개. 1회 최대 18개, UTC 하루 성공 호출 최대 24개. 비용 원장 조회 실패 시 새 검색 중단. 기존 월간 예산 가드 적용. 원장 추정액은 모델 토큰 비용이며 검색 도구 과금은 공급자 청구에서 별도로 확인해야 함.

## 운영 주기
운영 Vercel Hobby가 30분 cron을 거절한 것을 확인. 요금제 변경 없이 `10 21 * * 1-5` 적용: 한국시간 화~토 오전 6시 10분에 미국장 마감 후 수집 시작. Hobby cron 실행은 정밀한 시각을 보장하지 않으므로 실제 시작은 늦어질 수 있음. 다음 예정 수집 + 2시간 뒤까지 갱신되지 않으면 지연 표시. 주말을 수집 장애로 오인하지 않음.

장중 30분 갱신은 미구현 운영 범위. 별도 스케줄러/요금제 결정 후 예약만 변경하고 수집량·검색 비용 재검수 필요.
