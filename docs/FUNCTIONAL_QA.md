# 기능 검수 기준과 2026-10-18 결과

운영 기준을 복제한 격리 소스에서 확인한다. 기능이 보인다는 것과 실제 데이터·저장이 검증됐다는 것을 구분한다. 테스트 개수만으로 전체 서비스가 정상이라고 결론 내리지 않는다.

## 반복 실행

```sh
npm run verify
npm run build
npm run check:public -- http://localhost:3042
npm run check:public -- https://joobi.kr
```

`check:public`은 공개 페이지·시세·검색·뉴스·브리핑·경제 일정·시장 지표·시장 움직임과 비로그인 접근 제한을 47개 읽기 검사로 확인한다. AI 생성, 브리핑 수집, 개인 포트폴리오 쓰기, 알림 발송은 수행하지 않는다. 외부 공급의 `no_data`/미제공은 별도 집계하며 성공으로 세지 않는다. `fail`이 있으면 종료 코드 1이다. 뉴스/지표의 기사 사실관계나 원인 해석 전체를 검증하는 도구는 아니다.

새 회귀 검사는 기본 Vitest에 포함돼 기존 prebuild와 CI verify에서 실행된다. 외부 공급 장애가 있는 검사는 실패 원인을 확인한 뒤 처리하며 검사를 임의로 제거하지 않는다.

## 수정한 주요 결함

1. 초기 인증 요청 실패·무응답이 끝없는 준비 화면으로 남을 수 있었음. 오류와 재시도를 제공하고, 실패를 로그아웃이나 계정 없음으로 해석하지 않음. 초대·가입 조건·상세 시세·브리핑 조회도 기한을 두어 UI를 회복함.
2. 뉴스 공급 실패/차단 페이지가 정상 빈 기사 목록으로 응답했음. HTTP 502·캐시 금지로 구분하고 유효한 지역 fallback 후에만 기사 없음 판정.
3. 20거래일 이하 자료는 가격 차트까지 누락됐음. 가격 이력과 기술 지표의 필요 자료 수를 분리함. 잘못된 시계열은 차트에 넘기지 않고 재시도 제공.
4. 보유 수량이 있는데 시세 조회 전 “미보유”로 표시했음. 시세 확인/매입가 미입력을 구분.
5. 미수신 시세를 0으로 계산해 효과 분산 수치를 만들었음. 자료가 불완전할 때 구성 점수를 표시하지 않음.
6. 편집에서 음수·비정상 숫자와 불완전 추가 매수값을 저장할 수 있었음. 필드·범위·계산 결과의 유효성을 저장 전에 확인함.
7. 분류 버튼이 저장 전에 목록을 바꾸고 취소로 되돌리지 못했음. 로컬 초안 후 한 번에 저장. 이동한 항목의 기존 인덱스로 다른 종목을 편집하는 문제와 매도 종목 메모를 수정할 때 자동 재분류되는 문제도 수정.

8. 운영 공개 검사에서 배치 시세가 한 차례 누락됐고 단독 재조회에서는 회복됐음. 미국 종목 주 공급자 오류·잘못된 가격일 때 대체 조회가 없는 공통 경로를 수정. 키 미설정도 대체 공급자로 조회하며, 두 공급자가 모두 실패하면 미확인 값을 그대로 유지. 실제 누락 당시의 상류 상태나 구체 종목은 저장하지 않아 특정 공급자의 429로 확정하지 않음.

## 직접 검증하지 못한 항목

- 실제 카카오 OAuth 완료와 만 18세·약관 동의 제출. 관련 인증/동의 경계는 자동 검사로 확인했으며 타인 대신 동의하지 않음.
- 실제 사용자의 두 계정/두 기기 사이 클라우드 저장·복구. 샘플 UI와 모의 DB/경합 자동 검사 결과만 있음.
- 이메일/푸시 실제 발송·수신. 발송이나 구독 변경을 수행하지 않음. 알림 계산·인증·저장 경계 기존 검사를 사용함.
- 실제 iPhone Safari, 설치형 PWA·오프라인 전환·접근성 기기. 데스크톱 Chrome의 모바일 크기 검사는 Safari 검증을 대신하지 않음.
- 실제 성인 계정으로 AI 유료 공급을 호출하는 전체 응답. 요청 권한·한도·응답·취소·오류 처리는 기존 자동 검사로 확인.
