# 2026-10-02 모바일 UI 검수

## 판단 기준
- 토스증권 수준의 편안함·화면 정돈·쉬운 정보 전달을 최소 목표로 삼는다.
- 첫 화면에서 핵심 숫자와 종목을 빠르게 찾고, 자세한 설명으로 자연스럽게 이어진다.
- 화면을 정리한 이번 변경만으로 경쟁 서비스보다 좋은 제품임을 주장하지 않는다. 이해도·과업 성공률·반응 속도·재방문은 실제 사용자 검증이 필요하다.

## 변경
- AI 요청과 주요 조작 버튼, 설정 분류, 전체 메뉴 타일을 중립 토큰으로 통일. 손익의 빨강·파랑과 의미 있는 상태 색상은 유지.
- 비어 있는 포트폴리오의 중복 안내와 0건 분류 탭 제거. 검색·자주 찾는 종목·샘플 체험으로 진입 경로 정리.
- 모바일 자산 화면에서 큰 인사와 중복 시장 상태 제거. 전체 손익·오늘 변화를 우선 보여주고 자산/주간/월간 수치는 펼쳐 확인.
- 한국어 어절 보존, 제목 balance, 설명 pretty, 의미 묶음 적용. `설정할 수 있어요` 같은 서술어는 묶어서 줄바꿈. 좁은 화면/큰 글자에서 묶음 내부 줄바꿈도 허용.
- 입력 포커스 유지·복원, 모달 Tab/Escape 순환, 중첩 스크롤 잠금, 키보드 뷰포트 대응, 바텀시트 내용 스크롤과 손잡이 드래그 분리.
- 주요 Zustand 구독 축소, 무거운 화면 지연 로딩, 숨겨진 탭의 주기 요청 생략, 초기 및 자동 갱신의 중복 지수/시세 요청 제거.
- 환율을 못 받았을 때 편집창의 `현재 환율`을 `환율 미확인 · 임시 기준`으로 표시. 환산 경고는 요약을 접어도 유지.

## 남은 검증과 기존 문제
- 실제 iPhone Safari/Android에서 키보드 열고 닫기, 입력 후 저장, 바텀시트 손잡이 터치, 중첩 모달 확인.
- 큰 글자와 화면 읽기 도구를 사용하는 실제 환경 확인. FPS/INP 개선 수치는 아직 측정하지 않았다.
- 기존 USDKRW=X fallback 404는 별도 조사 필요. 이번에는 임시 값을 실제 시세로 표시하지 않도록 안내를 고쳤으며 환율 공급 경로를 바꾸지 않았다.
- 개발 분석 이벤트 CSP 차단, 로컬 Vercel 분석 스크립트 404는 별도 환경 확인 대상. CSP를 완화하지 않았다.
- 로그인 이후 저장/동기화, 관리자 화면, 실제 계정·외부 발송·결제는 이번 모바일 UI 검수 범위에 포함되지 않는다.
- 최초 검수 시점에는 로컬 수정만 완료했고 운영 커밋은 `3fd5105`였다. 사용자 반영 요청(2026-10-02)에 따라 검수한 변경을 main에 커밋하고 Git 연동 Vercel 운영 배포로 반영한다. 배포 결과는 세션 기록에서 확인한다.
