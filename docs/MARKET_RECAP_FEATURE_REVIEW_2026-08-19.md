# 시장 마감 수급·매크로 해설 기능 — 이중 독립 분석 (2026-08-19)

> 파운더 제안: "하루 장이 어땠는지 알려주거나 분석해주는 기능 — 기관·외국인·개인·프로그램 수급,
> 미국 국채금리, 그리고 '외국인이 사면/금리가 오르면 어떻게 되는지' 분석·조언."
>
> 방법: 동일 브리프로 **Codex**(단독 심층)와 **Claude**(5렌즈 병렬 + 렌즈별 적대적 검증 + 종합, 11에이전트)를
> 독립 실행 후 교차 대조. 코드 주장 및 검증관 신규 발견은 별도 재검증했다.

## 1. 최종 판정 — 양측 수렴

| | Codex | Claude(종합) |
|---|---|---|
| 판정 | **조건부 GO** | **조건부 GO — 원문 범위의 약 1/4만** |
| 즉시 가능 | 미국 10년물 표시 + 양방향 교육 카드 | 동일 (v1, S 규모 ~반나절) |
| 한국 수급 | 유료 계약(KRX/Koscom) 선행 조건 — 0단계 통과 못하면 중단 | 무료·합법 소스 부재로 착수 불가, 유료화 후 재검토 |
| 해석·조언 | 원문 그대로는 불가 — 사실 병렬 + 양방향 교육으로 변환 | §6 3요건 결합 구간 — 교육 카드로만 대체 가능 |
| 우선순위 | **세무 P0, 이 기능 P1** | 세무 v1과 경쟁하지 않는 v1 조각만 허용 |

방향이 다른 유일한 지점: Codex는 "KRX/Koscom 견적 문의를 지금 병행할 가치"를 인정,
Claude는 "유료화 검증 후로 미루되 공공데이터포털·KOFIA 무료 경로 배제 확인(1시간)만 선행"을 권고.

## 4. §6 카피 경계 — 되는 것 / 안 되는 것

**되는 것** (사실 병렬 + 교육):
- "오늘 코스피에서 외국인은 3,200억 원 순매수, 기관은 1,100억 원 순매도였어요." (인과 접속어 0)
- "외국인 순매수가 뭐예요? — 산 금액에서 판 금액을 뺀 값이에요. 순매수라고 지수가 꼭 오르는 것도 아니에요."
- "미 10년물 4.32%, 어제보다 +0.05%p. 금리가 오른 날 주식시장이 내린 날도, 오른 날도 있어요."
- "오늘은 외국인이 사고 지수가 오른 날이에요. 이런 날이 이어질지는 아무도 몰라요."

**안 되는 것**:
- "외국인이 이렇게 사는 날엔 보통 지수가 올라요." — 조건부 일반화 = 실질 매매권유, **현행 lint 사각**
- "지난 1년 외국인 순매수일의 68%는 상승 마감" — 자체 검증 통계여도 확률 예측 프레이밍(변호사 게이트 전 금지)
- "외국인이 삼성전자 5일 연속 순매수 — 수급 개선 신호" — 종목 특정+신호, 3요건 완성
- "외국인 순매수 상위: 삼성전자…" — 해설 없어도 랭킹 큐레이션 = 군중 추종 유인
- 순매수 초록/순매도 빨강 색코딩, 수급 급변 푸시 알림, '스마트머니·세력·매집·저점 가능'

## 5. 넘으면 안 되는 선 (요약)

1. 조건부 일반화("X면 보통 Y") 전면 금지 — 신규 FLOW 금지어 가드를 **카피보다 먼저 커밋**
2. 종목 단위 수급 금지 — v2가 열려도 시장 전체 집계까지만
3. 인과 접속어 금지 — '때문에·덕분에·배경·여파'
4. 과거 승률/분포 통계 금지 — 변호사 게이트 전
5. 수급·금리 숫자에 손익색 금지 — 중립색만
6. 비공식 스크래핑 금지 — "일단 크롤링으로"는 예정된 실패 경로
7. MorningBriefing(개인화 문맥)에 수급 해석 결합 금지 — 링크만

## 6. 만든다면 — v1 스펙 (S, 반나절)

1. 미 10년물을 MACRO_IND에 추가 — Treasury.gov cron 1일 1회(주) 또는 기존 quotes ^TNX(부). `type: 'yield'` 분기: % 표기 + **중립색**
2. 정적 교육 카피 1~2장 — 신규 `macroContextCopy.ts` (marketFlow* 네이밍 금지 — 기존 파일과 충돌)
3. 같은 커밋에 누출 불변식 테스트(sec6StaticCopy식) + feature_first_use 텔레메트리(없으면 검증 아닌 시연)
4. 얹는 곳: MacroStrip(숫자) + 리포트 탭 기존 프레임(교육 카드). **새 탭·새 위젯 금지**

선행 조건(v1과 무관하게 이미 등재): marketFlow vs MorningBriefing **판정 엔진 이중화 해소**(THRESHOLDS.md §11).

1. **범위 축소 수용** — "분석·조언"은 어떤 구현으로도 출시 불가. "사실 표시 + 교육 카드" 축소에 동의하는가? (부동의 = 전체 NO-GO)
2. **v1(미 10년물, 반나절) 착수 시점** — 지금 vs 세무 뒤
3. **한국 수급 유료 견적** — 지금 문의 vs 유료화 후 (권고: 후자 + 공공데이터포털·KOFIA 배제 확인만 선행)
4. **P2 금기(KIS·KRX) 명문화** — 저장소에 근거 문서가 없음. 유지든 번복이든 문서화
