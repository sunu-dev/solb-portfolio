## 1. 종목 AI 분석

- 엔드포인트: `POST /api/ai-analysis`
- 인증: 로그인 사용자 전용, 서버에서 Bearer token 검증
- 사용자 입력:
  - 종목, 현재가, 등락률
  - 보유수량, 평균 매수가, 현재 손익
  - 목표 수익률, 손절가, 포트폴리오 비중
  - 투자자 유형, 종목 결정 메모
- 시장 입력:
  - RSI, 추세, 이동평균 교차, 패턴, 볼린저 밴드, MACD, 거래량
  - PER, EPS, 52주 고저, 섹터
  - 최근 뉴스, 시계열 컨텍스트
- 출력 방향성:
  - 긍정/관망/주의 결론과 신호
  - 상승·하락 시나리오
  - 레버리지·인버스는 서버 후처리로 방향성 제거
- 저장:
  - `ai_usage`: 사용자·종목·멘토·날짜
  - `ai_cost_ledger`: 모델·토큰·추정 비용·지연시간
  - 프롬프트와 응답 원문은 비용 원장에 저장하지 않음
- 남은 위험:
  - 개인 보유정보와 목표를 직접 반영하므로 법령해석 자료의 핵심 검토 대상
  - 응답 캐시가 없어 동일 조건 반복 호출 시 비용이 다시 발생

## 2. AI 촉

- 엔드포인트: `POST /api/ai-chok`
- 인증: 서버에서 사용자 확인
- 개인화 입력:
  - 보유 종목 제외 목록
  - 투자자 유형
  - 핵심 보유 종목의 비중·신호·메모 맥락
  - 포트폴리오 섹터 집중도
- 시장 입력:
  - 종목별 현재가, 당일 변동률, PER, 52주 위치
  - VIX 구간, 시장 이벤트, 당일 상승·하락 상위
- 캐시 키:
  - 사용자 + 투자자 유형 + KST 날짜 + day/night 세션 + VIX 구간
- 비용 없는 경로:
  - `intent=fetch`
  - 정확 캐시 또는 최근 24시간 캐시
  - 객관 수치 기반 결정론적 폴백
- 출력 방향성:
  - 서로 다른 섹터의 관찰 후보 3개와 이유
- 저장:
  - `ai_chok_cache`, `ai_chok_recommendations`, `ai_usage`, `ai_cost_ledger`
- 남은 위험:
  - 사용자의 포트폴리오 약점을 보완하도록 후보를 고르는 구조는 개인화 추천으로 해석될 가능성이 큼

## 3. 알림과 digest

- `check-alerts`, `morning-brief`, `monthly-d3-reminder`는 현재 LLM을 호출하지 않는다.
- 사용자 포트폴리오와 설정값을 서버 규칙·템플릿으로 조합한다.
- 비용 원장 대상은 아니지만 목표·손절 등 방향성 문구에 대한 컴플라이언스 감사 대상이다.

## 4. 보조 AI 기능

### 포트폴리오 OCR

- 사용자가 업로드한 이미지가 Gemini로 전달된다.
- 이미지 자체는 주비 DB에 저장하지 않으며, 성공 시 사용자 ID 또는 비로그인 IP와 인식 종목 수를 `ai_usage`에 기록한다.
- 모델·토큰·지연시간·추정 원가는 공통 비용 원장에 `portfolio-ocr`로 기록한다.
- 전체 AI 일일 하드캡과 OCR 전용 일일 하드캡을 모두 적용하며, 공급자 데이터 처리 조건은 별도 확인해야 한다.

### 신규 상장 한글명 보강

- 종목 코드·영문명·거래소만 전달한다.
- 투자 개인화가 없고 관리자 보조 기능이다.
- 공통 프로바이더를 사용하며 비용 원장에 `admin-listing-name`으로 기록한다.

## 2026-11-04 직접 질문과 내 주식사전
- `/api/ai-analysis`의 `ask-joobi`: 기존 로그인·성인 동의·분당/일일/월 비용 제한을 재사용한다. 추가 전송 확인이 있는 2~600자 질문, 선택 종목, 최대 8개 알려진 용어 ID만 신규 입력으로 받는다. 브라우저가 붙인 시세·뉴스·보유정보·메모는 사용하지 않는다.
- 회사 설명/상품 구조/가격은 서버 공개 자료로 읽는다. 질문 원문·답변은 `sampleAiOutput`에 보내지 않는다. 비용/횟수 기록에는 기존 계정 ID·종목·모델·토큰만 남는다.
- 로그인 사전은 `public.personal_dictionary`에 보관한다. auth.uid() RLS, 계정당 300개, 행 revision 비교로 다른 계정 접근과 오래된 수정 덮어쓰기를 막는다. 회원 탈퇴 시 FK cascade로 삭제한다.
- 게스트는 `joobi_dictionary_v1:guest`에 보관한다. 익명 새로고침은 유지하고 로그인·계정 전환·로그아웃 경계에서는 정리한다. 계정으로 자동 복사하지 않는다.
- 사전 메모는 AI에 자동 전송하지 않는다. ‘아직 헷갈려요’ 용어 ID만 사용자가 질문 전송 안내를 확인한 뒤 제공한다. 복습은 유지 중인 용어 정의에서 생성하며 모델 호출이 없다.


## 2026-11-04 공개 근거를 연결한 후속 질문
- 직접 질문에 선택 시장·비교 기간과 현재 화면의 최근 대화 최대 3개를 동의 후 함께 전송한다. 이전 대화는 질문 해석용이며 현재 사실 근거가 아니다.
- 시세/회사 뉴스 제목/기존 공개 시장·기업·정책 자료를 서버에서 연결한다. 클라이언트 임의 시세·뉴스·보유정보는 사용하지 않는다.
- 공개 근거만 60초/200키 프로세스 캐시. 질문·답변은 캐시하거나 검수 저장하지 않는다.
- 기존 자동 거래일 배경 AI 설명에서 가격과 반대인 내용이 발견되어 공개·추가 생성을 중단했다. 시세 수집과 계산 비교는 유지한다.
- 구체적 계약과 한계: `docs/JOOBI_ASSISTANT_ENGINE.md`.

### 하이쿠 직접 질문의 공개 기사 조회 (2026-11-04)
직접 질문은 Haiku 5.5로 고정한다. 인증·성인 동의·횟수·월 예산 검사 뒤, 관련 시장 질문에 한해 공개 종목/시장/거래일로 검색 1번과 원문 최대 2개를 요청한다. 검색 요청에는 질문 원문·최근 대화·개인 계좌 내용을 포함하지 않는다. 기사 원문에서 추린 문단은 답변 모델 입력으로만 쓰고 사용자 브라우저에는 재배포하지 않는다. 5분 프로세스 캐시는 공개 기사만 저장하며 비용 원장에는 검색 비용을 포함한 사용량만 기록한다. 질문·답변의 별도 서버 이력 저장은 하지 않는다. 새 데이터베이스나 예약 작업은 없다.
