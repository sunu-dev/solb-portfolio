# 주비의 제품 및 설명 원칙

## 고정된 제품 방향
사용자 확정: 2026-09-19. 기능 기획, 콘텐츠, 문구, 화면 구성의 공통 판단 기준이다.

- **정체성: 주식비서.** 시장에서 일어난 일을 챙겨주고, 그 일이 사용자의 투자와 어떻게 이어지는지 설명한다.
- **핵심 타깃: 주식 초보자.** 금융 용어나 티커를 이미 안다고 가정하지 않는다. 익숙한 한국어와 생활 속 예시로 설명한다.
- **서비스 목표: 오래 머무르고 다시 찾는 경험.** 읽을수록 이해가 쌓이고 자신의 투자에 필요한 정보를 발견해, 지속적으로 이용할 이유를 만든다.
- **사용성 기준: 토스증권.** 사용자 확정(2026-10-02): 편안함, 깔끔한 화면, 정보 전달의 쉬움은 최소 비교 기준이다. 주비는 이를 갖추고 시장 변화와 내 투자 사이의 관계를 더 잘 이해하게 만드는 경험을 목표로 한다. 이 기준을 문서화했다고 경쟁 서비스보다 우수함이 검증된 것은 아니다.

## 기능과 화면의 판단 기준
- 초보자가 ‘이게 뭐예요? 왜 알아야 해요? 내 주식에 어떤 영향을 줄 수 있어요?’에 답을 얻을 수 있어야 한다.
- 첫 화면에는 지금 중요한 내용을 간결하게 보여준다. 궁금한 내용을 누르면 영향 경로, 관련 정보, 기록으로 자연스럽게 이어지도록 한다.
- 발표 전에는 일정과 알아둘 점, 발표 후에는 확인된 결과와 의미, 이후에는 달라진 상황을 연결한다. 다시 방문했을 때 새롭게 확인할 내용이 있어야 한다.
- 체류시간과 재방문율을 함께 살피고, 설명을 이해했는지와 필요한 정보를 찾았는지도 확인한다. 기능을 추가할 때 이 경험에 어떤 도움이 되는지 설명할 수 있어야 한다.
- 이 방향은 FOMC에 한정하지 않고 경제지표·실적·정책·뉴스 등 모든 이벤트와 서비스 전반에 적용한다. 각 유형의 실제 제공 여부는 아래 적용 범위와 구분한다.

## 핵심 가치
세상의 변화가 내 투자와 어떻게 연결되는지 풀어주는 주식비서.

사용자가 뉴스 제목이나 약어를 이미 안다고 가정하지 않는다. 읽고 나서 사건의 뜻과 영향이 전달되는 과정을 이해하고, 무엇을 더 살펴봐야 하는지 알 수 있어야 한다.

## 공통 구성
1. **무슨 말인가요?** 용어의 뜻을 생활 언어 한두 문장으로 설명한다.
2. **무슨 일이 있었나요?** 확인된 발표 결과와 기준 시점을 보여준다. 예정/결과 확인 중/실제 결과를 구분한다.
3. **왜 그런가요?** 발표 주체가 밝힌 이유가 있을 때 출처와 함께 설명한다. 확인되지 않은 동기를 만들어내지 않는다.
4. **어디로 이어지나요?** 사건 → 금리·환율·원자재·수요 같은 중간 변화 → 기업의 비용·매출·투자 → 실적 기대와 주식 평가의 연결 중 관련 있는 경로를 보여준다.
5. **내 투자에서는 무엇을 보나요?** 확인된 보유 종목·시장·업종 정보에 따라 점검할 항목을 연결한다. 단지 주식을 보유했다는 이유로 모든 사건의 직접 피해·수혜 종목이라고 단정하지 않는다.
6. **달라질 조건은 무엇인가요?** 시장의 사전 예상, 반대 방향의 효과, 기업별 차이, 시간차를 짧게 설명한다.

## 설명의 깊이
- 브리핑/리포트 첫 화면: 용어 한 줄 + 실제 핵심 + 의미 요약.
- 상세: 단계별 연결 + 생활 속 예시 + 달라질 조건 + 출처.
- 모든 설명을 첫 화면에 펼치지 않는다. 더 알고 싶은 사용자가 한 번 눌러 이어서 읽도록 한다.
- 약어를 다른 약어로 설명하지 않는다. 예: EPS → ‘이익을 주식 한 주 기준으로 나타낸 값’.

## 예시와 사실
- 가상의 카페 회사, 가계 지출 등은 이해를 돕는 예시라고 표시한다.
- ‘금리를 올리면/내리면/그대로 두면’은 학습용 상황 선택이다. 버튼을 눌러도 실제 발표 결과가 바뀌지 않는다.
- ‘물가가 둔화했다’는 사실과 ‘금리 부담이 완화될 수 있다’는 해석을 분리한다.
- 날씨 → 수급 → 원자재 가격 → 기업 이익처럼 멀리 이어지는 설명은 중간 단계의 근거를 생략하지 않는다. 연결이 확인되지 않으면 직접 관련성을 주장하지 않는다.
- 실제 주가가 움직였다는 사실만으로 그 사건이 원인이었다고 서술하지 않는다.

## 현재 적용 범위
- 경제 일정의 FOMC·CPI·PCE·미국 고용·한국은행·기업 실적·휴장일, 총 7개 유형에 공통 뜻풀이/영향 경로/생활 예시/조건을 제공한다.
- `economicEducation.ts`가 유형별 설명, `EventLearning.tsx`가 공통 표현을 담당한다.
- 뉴스·관세·정책·원자재·재해 등 새 콘텐츠에도 위 원칙을 적용할 수 있다. 이 문서 작성만으로 해당 데이터 수집이나 사건별 맞춤 분석이 구현된 것은 아니다.
- 국내 실적, 경제지표 예상치 등 데이터 공급 범위는 `ECONOMIC_BRIEFING.md`를 따른다.
