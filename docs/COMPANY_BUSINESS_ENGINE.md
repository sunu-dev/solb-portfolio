# 기업 설명 엔진 v1

주식 초보자가 ‘무엇을 하는 회사인지, 누가 쓰는지, 어떻게 돈을 버는지’를 근거와 함께 이해하도록 하는 공통 처리 경로다. 종목 하나의 누락을 전체 카탈로그 결함으로 다룬다. 전체 8,020기업 후보를 유지하고 분류 충돌·국내 공급원 미설정을 분모에서 숨기지 않는다.

## 흐름
1. **전체 대기열:** 정적 검색 카탈로그의 기업 후보를 500건씩 최초 등록한다. 재실행은 이미 있는 행을 갱신하지 않는다. 대표 노출 기업832개(배치836곳)를 우선하지만 나머지도 대기열에 남는다.
2. **실체 확인:** SEC 공식 티커·CIK 목록과 해당 CIK의 submissions 티커를 교차 확인한다. 국내는 OpenDART 고유번호·종목코드와 기업개황을 교차 확인한다. 이름 유사도나 AI가 고른 주소로 회사와 출처를 연결하지 않는다.
3. **원문 수집:** 최신 10-K/20-F(정정 포함), 국내 사업보고서를 공식 목록에서 찾는다. 등록 도메인·고정 경로, 리다이렉트 차단, 크기·시간·ZIP 제한, 요청간1.1초 간격을 둔다. 정정 보고서에 사업 내용이 없으면 오래된 본문으로 조용히 대체하지 않는다.
4. **사업 구간 추출:** 표 안의 제목·문장부호·레이아웃용 셀까지 읽고 제목 구조로 사업 구간과 위험요인/재무 구간을 나눈다. 문서 최대32MB, 텍스트 블록12000개 제한을 유지한다. 보이는 본문만 후보로 삼는다. 키워드 점수는 근거 후보를 추리는 용도이며 사실 판정이 아니다. 구간을 확인하지 못하면 보류한다.
5. **한국어 설명 초안:** 하는 일·고객·수익 구조·점검 관점, 각35~220자. 각 항목에 원문의 정확한 구절과 문단ID를 연결한다. 금액·비율·주가 전망을 만들어 넣지 않는다. 데이터는 명령이 아니며 도구/임의URL/보유기록을 모델에 주지 않는다.
6. **검수:** 기업·자료·초안 지문을 묶고 별도 검수 요청이 네 항목의 뒷받침·충분성·초보자 이해도를 확인한다. 정확히 인용했다는 사실만으로 문장 의미가 입증되지는 않는다. 위험 가정을 현재 사업으로 표현하면 거절한다.
7. **편집 검수 후 공개:** v1은 모델이 자기 결과를 공개할 수 없다. 원문·회사 일치·전체 주장·초보자 표현을 실제 확인한 별도 편집 검수 기록과 정확한 버전 지문이 필요하다. 수집·초안·검수 자동화와 무인 공개는 구분한다.
8. **저장·갱신:** 공개 조회는 준비된 설명만 읽는다. 7일 뒤 원문 재확인, 8일 확인 만료 또는550일 지난 자료는 공개 보류. 원문이 바뀌면 먼저 기존 승인을 무효화한다. 바뀌지 않은 문서에는 모델을 다시 호출하지 않는다.

## 운영 경계
- 단일 활성 작업·5분lease·fence 검증, 실행당1기업, 초기 운영 예약은 일1건, 수동 점검을 포함한 상한은 일2건. 기존 시장설명 공통 비용 원장을 공유한다. 불확실 호출 예약을 지우거나 일/월 한도를 올리지 않는다.
- 정상 초안은 검수 호출 전에 저장해 검수 장애 때 재작성 비용을 막는다. 실패는 하루 뒤 재시도,3회 누적 실패는30일 대기. 예산 보류는 다음UTC일자로 넘기며 실패 횟수로 소비하지 않는다.
- 무료 요금제에 맞춘 `00:20 UTC` 일1회 예약. 초기 작업허가 만료는2026-11-14 08:00UTC(17:00KST). 실제 품질·비용·처리량을 평가한 뒤 연장한다. 일1회 예약/일2건 상한은 검증 단계이며8,020개를 빠르게 채우는 처리량이 아니다.
- 자동 무인 공개는 현재 꺼져 있다. 속도를 높이려면 실제 검수 표본과 생성 비용, 재시도율, 자료 누락율을 측정하고 처리량/편집 검수 운영을 결정해야 한다.
- 원문 지문·검수·승인은 private schema에 저장한다. 익명/로그인사용자는 대기열 조회·수정·생성·승인을 실행하지 못한다. 공개 API에는 설명·출처·자료일·확인일·만료일만 전달한다. 공개 중지/철회 시 과거 정적 설명을 되살리지 않으며, 저장소 장애 때는 철회 여부를 확인할 수 없어 설명을 잠시 보류한다. 오류 로그에 공급자 응답·키·사용자 정보를 넣지 않는다.
- 기존5개 수동 상세 설명은 그대로 유지하며 이번 엔진에서 새로 검증한 회사 수로 계산하지 않는다. 본 엔진은 연차보고서의 사업 설명용이다. 실시간 사업 변경·M&A 공시 추적, 실적 예상/결과, 가격 등락 원인 엔진과 구분한다.

## 작업 명령
`node scripts/company-business-engine.cjs inventory|audit-sources|status|verify|apply|seed|worker-on|worker-off|publication-on|publication-off`

`audit-sources`는 전체 카탈로그의 공식 발행사 목록 연결 상태를 집계하며, 목록 일치를 사업 설명 완료로 계산하지 않는다. 영문자가 섞인 국내6자리 코드를 국내로 분류한다.

`collect SYMBOL`은 읽기전용 실제원천수집, `run SYMBOL`은 서버 환경에서 지정된 큐 작업1건을 처리한다. `inspect SYMBOL`은 편집 검수용 원문구절/초안/판정과지문을 파일로 저장한다. `review-packet SYMBOL`은 원문·초안·검수 상태를 읽기 전용 HTML로 나란히 보여준다. 초안이 없으면 없다고 표시하고 파일을 열거나 검사하는 행위로 승인하지 않는다. `approve SYMBOL review.json`은 해당 버전의 실제 편집 검수기록이 있어야 한다. 원천키·서비스키는 환경변수로만 설정하고 채팅/로그/보고서에 쓰지 않는다.

편집 검수 파일: `symbol`, `kind:"editorial"`, `evidenceHash`, `draftHash`, `identityChecked:true`, `claimsChecked:true`, `beginnerChecked:true`, 20자이상 `note`. 이 파일을 모델이 만들도록 요청하거나 통과용 문구로 자동 생성하지 않는다.

## 일시 조회 실패
회사 설명 저장소가 일시적으로 응답하지 않으면 HTTP503·no-store로 반환한다. 실패를 정상 설명처럼 CDN에 보관하지 않는다. 화면은 과거 설명을 되살리지 않고 다시 불러오기 버튼으로 해당 설명만 재요청한다.
