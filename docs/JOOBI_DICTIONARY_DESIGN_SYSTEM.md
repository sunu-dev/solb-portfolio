# 주비 주식사전 디자인 시스템

2026-11-06 사용자 선택: A 새싹 링 수첩(전체 사전) + J 빼꼼 미니 수첩(읽던 자리의 용어 설명).

## 역할과 진입점

- A: 내 단어 목록, 전체 용어 검색, 이해 정도 표시, 개인 메모, 선택 퀴즈. PC 전체 메뉴·모바일 더보기·책 아이콘이 같은 사전을 연다.
- J: 종목 설명과 주비 대화의 밑줄 용어를 누르면 뜻·예시·관련 용어를 보여준다. 저장 후 A로 이어갈 수 있다.
- 관련 용어를 읽어도 원래 종목과 대화를 바꾸지 않는다. 창을 닫으면 가능한 경우 열었던 버튼으로 포커스를 돌린다.
- A/J는 화면 구성만 다르며 용어 정의, 계정별 저장, 저장 한도, 퀴즈 정답 근거를 공유한다. 새로운 AI 호출이나 개선 엔진을 추가하지 않는다.

## 시각 규칙

구현의 기준은 `src/components/learning/DictionaryTheme.module.css`이다. A는 `StockDictionary.module.css`, J는 `FinancialText.module.css`가 배치만 담당한다.

| 표지 | #d6dfc4 | #394530 |

- 기존 새싹 캐릭터를 사용하며 설정에서 선택한 강아지도 존중한다. 캐릭터·링·테이프·종이 무늬는 장식이고 클릭이나 포커스를 받지 않는다.
- 서버 연결 실패 안내도 같은 종이·강조색·버튼을 사용한다. 저장 목록 조회 실패를 단어 0개로 표시하지 않는다. 기본 용어 읽기와 계정 저장 가능 여부를 구분한다.
- 제목·단어 이름에는 기존 Single Day 글꼴, 설명·입력·버튼에는 시스템 글꼴을 사용한다. 긴 설명을 손글씨로 표시하지 않는다.
- A 사전 설명 본문은 PC 18px·모바일 17px, 예시는 16px. 입력은 16px, 설명 줄 간격은 약 1.9. 버튼 터치 영역은 최소 44px. 보조 안내는 12–14px.
- 종이/표지/테이프의 색을 개별 컴포넌트에 다시 정의하지 않는다. 새 상태도 공통 변수와 버튼 클래스를 사용한다.
- 빈 화면 문구: “저장한 단어가 없어요. 아래에서 뜻을 읽고 저장할 수 있어요.” 과도한 의인화나 저장을 유도하는 감성 문장을 쓰지 않는다.

## 화면과 상태

| 상태 | 동작 |
|---|---|
| 비어 있음 | ETF·수익률·주식·거래량부터 읽고 저장 가능. 0문제 퀴즈 버튼은 노출하지 않음 |
| 불러오는 중 | 저장된 단어를 불러온다는 상태 문구 |
| 저장 중/완료 | 중복 제출 차단, 성공 후에만 저장됨 표시 |
| 읽기/쓰기 실패 | 오류 안내와 재시도. 저장 성공으로 꾸미지 않음 |
| 검색 결과 없음 | 다른 말로 검색할 안내, 직접 추가 기능 유지 |
| 직접 추가한 미확인 단어 | 개인 메모로 관리하되 퀴즈 정답 자료로 사용하지 않음 |
| 게스트 | 이 브라우저에 저장. 로그인 계정으로 자동 이전하지 않는 실제 동작 안내 |
| 로그인 | 계정별 DB 저장. 다른 계정 데이터와 섞지 않음 |
| 퀴즈 | 검증된 용어 정의로 최대 3문제. 본문을 읽기 위한 조건이 아님 |

## 반응형·접근성

- PC A: 목록과 설명을 나란히, 표지 오른쪽 분류 탭. 최대 너비 1100px, 높이 800px. 목록과 설명 비율은 0.7:1.3으로 읽는 공간을 우선한다.
- 모바일 A: 상단 분류 탭, 목록 또는 선택한 단어 설명. “목록으로”로 돌아간다. 화면 안에 독립 스크롤을 두고 배경 이동을 잠근다.
- 내용이 넘칠 때 오른쪽 위치 표시를 노출하고, 위/아래에 내용이 남은 쪽에만 얕은 경계 그림자를 보인다. 내용 위에 이동 버튼을 겹쳐 놓지 않는다. 스크롤 영역은 키보드로도 이동할 수 있어야 한다.
- PC J: 오른쪽 아래 미니 수첩. 모바일 J: 화면 아래, 좌우 12px 여백. 긴 내용은 종이 내부에서 스크롤한다.
- native dialog로 초점 범위를 제한한다. Escape와 이름이 있는 닫기 버튼 제공. 포커스 표시를 없애지 않되 읽기용 제목에 불필요한 테두리를 붙이지 않는다.
- 지연 로딩 중 바깥 dialog에 잡힌 포커스는 사전 제목으로 옮긴다. dialog 자체 외곽선은 숨기고 버튼·입력의 키보드 포커스는 유지한다. 첫 열기와 다시 열기를 모두 확인한다.
- 저장한 단어가 없는 첫 화면의 기본 4개는 전체 수록 범위가 아니다. ‘전체 N개 단어 보기’에서 전체 목록으로 이동하며 수록 수는 실제 데이터에서 계산한다.
- 키보드가 줄인 실제 가용 높이는 기존 `useModalViewport`를 공유한다. 데스크톱 모바일 크기 검수는 실제 iPhone 키보드 검수를 대신하지 않는다.

## 변경 관리

- 사용자 선택 전의 10개 시안은 `artifacts/dictionary-analog-concepts-20261106`에 보존한다. 운영에서 열 가지 테마를 동시에 관리하지 않는다.
- 정의/출처: `financialTerms.ts`. 계정 저장: `PersonalLearningProvider`/`personalDictionaryCloud`. 복습: `personalDictionary.ts`. 메뉴 이벤트: `dictionaryNavigation.ts`.
- 새 기능은 A/J 공통 상태에 연결한다. 계정·게스트 저장 범위나 퀴즈 근거를 UI 편의 때문에 바꾸지 않는다.
- 확인할 흐름: 메뉴→검색→뜻→저장→A 재확인→메모→재접속→퀴즈→닫기. J 관련 용어 이동과 A 연결도 확인한다.
- 별칭/카카오 이름 분리는 별도 작업이다. 이번 사전 UI 변경에 포함해 완료했다고 보고하지 않는다.

## 2026-11-10 검수 반영

- 삭제는 사전과 같은 종이·버튼 체계의 인라인 확인을 거친다. 단어와 메모·이해 표시가 함께 삭제됨을 안내하며 취소 시 삭제 버튼으로 초점을 돌린다. 실패 시 원래 항목을 유지한다.
- 첫 뜻 맞히기 퀴즈에서는 수익률/이익률/배당수익률처럼 이름이 비슷한 비율을 서로의 오답 보기로 배치하지 않는다. 서로 같은 개념이라는 뜻은 아니다.
- 거래량 예시는 독립적인 가상 주식 수 계산으로 설명한다. 특정 차트가 없는 사전에서 ‘이 화면’의 계산법을 전제하지 않는다. 출처는 Fidelity 거래량 정의로 연결한다.
- Claude Code Chrome 검수 원본과 재검증 결과를 함께 보존한다. 개발 서버 HMR 중 일시적 화면 문제와 미재현 관찰을 운영 결함으로 단정하지 않는다.

## 이해한 단어와 복습 제외 (2026-11-10)

- 사용자가 직접 “이해했어요”를 선택한 단어만 기본 내 단어 목록과 이후 퀴즈에서 제외한다. 읽기·정답 선택만으로 이해했다고 판단하지 않는다.
- “이해한 단어 숨기기”를 해제하거나 “이해한 단어 보기”를 누르면 다시 읽고 메모를 볼 수 있다. “다시 복습할래요”로 복습에 포함한다.
- 단어·메모·이해 표시는 기존 계정 저장 체계를 사용한다. 새로 열었을 때 이해한 단어 숨기기가 기본이며, 직접 검색하거나 용어 링크로 연 설명은 계속 읽을 수 있다.
- 퀴즈에서도 “이해했어요 · 복습 제외”를 제공한다. 실패한 저장은 기존 이해 상태를 유지하고 재시도할 수 있다.
- 저장됨이 서버 재조회로 확인되면 이전 저장 시도의 오류를 함께 표시하지 않는다. 저장 자체의 네트워크·DB 실패 원인 해결과 구분한다.
- 수익률 출처는 계산기가 아닌 FINRA의 Return and Rate of Return 정의 페이지로 연결한다.
