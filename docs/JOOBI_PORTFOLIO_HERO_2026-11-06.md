# 내 투자 첫 화면 정리 — 2026-11-06

## 목적과 화면 순서
사용자가 가장 먼저 평가금액과 손익을 확인한다. 주비·사전 도구와 거래시간 설명 때문에 핵심 수치가 아래로 밀리던 구조를 정리했다.

1. 내 투자 제목 + 주비·사전 44px 아이콘
2. 평가금액 + 통화 전환
3. 평가손익 + 기간별 변화·투자 원금
4. 계산 설명, 시장 상태 한 줄, 접힌 거래시간 안내
5. 기존 알림·투자 구성·종목 목록

## 공통 기준
- 기존 Pretendard, 흰 화면·중립 글자색과 손익 색상 토큰을 유지한다. 별도 장식 카드나 새 색상 체계를 추가하지 않는다.
- 금액은 30–42px, 손익은 24–30px. 숫자의 우선순위를 여백과 순서로 구분한다.
- `PortfolioTools`를 투자 등록 전후 공통으로 사용한다. 제목 옆에 배치하고 버튼마다 독립 행을 만들지 않는다.
- 데스크톱의 마우스 올리기·키보드 포커스에만 버튼 이름을 펼친다. 모바일은 44px 터치 영역과 접근성 이름을 유지한다.
- 주비 버튼은 질문창을 열고, 사전 버튼은 기존 공통 사전 창을 연다. 닫으면 누른 버튼으로 돌아온다.
- 홈의 거래시간 안내는 `UsMarketClockNotice home`으로 기본 접힘. 요약에 새싹과 실제 변경 제목을 함께 표시한다. 약 249px였던 초기 안내가 48px로 줄어든다.
- 안내 확인 시 접힘·포커스 복귀·확인 상태 저장은 유지한다. 확인한 안내도 다시 열 수 있다. 채팅 내부 안내의 표시 방식은 바꾸지 않는다.
- 평가금액과 손익 사이의 시장 상태·안내를 뒤로 옮기고 중복 소개 문장을 제거한다.
- 계산식·통화·매수환율 누락 처리·샘플 표시·기간 비교 의미는 유지한다.
