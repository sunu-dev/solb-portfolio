## 연료전지·분산발전
- BE를 사업 설명의 대표 출발점으로 유지하고 FCEL·PLUG를 공식 사업 소개와 함께 추가.
- FCEL은 발전용 연료전지, PLUG는 수소 연료전지와 공급망이라는 역할 차이를 설명.
- 공통 산업 이야기와 원본 업종 목록 모두 기업 카드에 티커를 표시.
- 대표 기업은 시가총액·매출·점유율 1위를 검증한 순위가 아니다.

## AI 응답
- Gemini에 JSON Schema를 제공하고, 서버에서도 화면에 필요한 필드·자료형과 완료 상태를 검증.
- 완전한 JSON 코드 블록은 허용하지만 잘린 응답·배열·null·필드 누락은 답변으로 제공하지 않는다.
- 형식 오류는 기존 모델·키 순회에서 재시도하고, 모두 실패하면 `502 invalid_ai_response`와 재시도 가능한 안내를 반환한다.
- 오류 문구를 성공한 분석 보고서로 반환하거나 캐시하지 않는다. 유효한 답변만 개인 일일 이용 횟수를 기록한다. 제공사 비용·키 사용 기록은 실패한 생성도 남긴다.
- 기존 개인정보 제외·서버 레버리지 판정·방향성 문구 후처리를 유지한다.
