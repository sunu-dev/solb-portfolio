# 초보자 설명에서 산업·상품 탐색으로

## 사용자 확정 방향

SOXL 한 종목의 문구 수정에 한정하지 않는다. 짧은 첫 설명, 처음 보는 단어의 뜻, 투자 대상과 산업, 실제 질문의 답, 다음 확인할 내용으로 이어지는 공통 흐름을 만든다. 학습이 쌓여 스스로 자료를 읽고 판단할 수 있게 돕는다. 방문하지 않는다고 학습을 마쳤다고 추정하지 않는다. 퀴즈·설명 작성 과제를 요구하지 않는다.

## 이번 구현 범위

- 등록된 301개 상품에 투자 대상과 구조를 여는 공통 입구를 제공한다. 확인한 20개 상품은 관련 산업으로도 연결한다. 다른 상품에 비슷한 이름만 보고 산업·구성 종목을 추정하지 않는다.
- 일반 기업도 공통 회사 소개에서 산업 탐색으로 연결한다. 기존 고객·수익 구조와 출처를 보존한다. 사업 소개가 없는 회사를 채웠다고 표시하지 않는다.
- ETF·기초지수·NYSE·NYSE 반도체지수와 기존 경제·기업 개념을 본문에서 바로 열어 뜻·예시·공식 출처를 읽는다. 용어 안의 다른 용어도 같은 창에서 이동하고 이전 용어로 돌아간다. 닫으면 본문의 원래 용어로 초점을 돌린다.
- 질문 버튼 안에 또 다른 용어 버튼을 중첩하지 않는다. 질문 제목은 쉬운 말로 쓰고 실제 답변의 전문 용어는 누를 수 있게 한다.
- 관련성이 있는 미독 답을 우선 제안한다. 답변을 다 읽은 뒤에는 새 질문을 만들어 클릭을 강요하지 않는다. 이미 읽은 설명은 추가 목록에서 다시 볼 수 있다.
- 반도체 카드의 그림을 레버리지 공통 그림과 구분한다. 산업 예시를 기준지수의 실제 구성 목록으로 표시하지 않는다.

## 개선엔진

0.5.0 수집기/탐지기와 루브릭 v2에 첫 설명·탐색·질문 경로·용어 창 전달 검사를 추가한다. 오류의 근거와 개선 과제를 유지하고 후속 운영 수집으로 전달·재발을 확인한다. 전체 내용의 의미 검수, 자동 코드 수정, 자동 배포는 이 규칙 검사와 구분한다.

자동 반복 실행은 켜지 않았다. 기존 Supabase 장애 보류, 검증 릴리스 결속, 부하·무료 할당량·편집 승인 조건을 유지한다. 회원 자료·계좌·메모·API 키를 이번 검사로 수집하지 않는다. 용어 열기는 외부 모델을 호출하거나 AI 사용 횟수를 차감하지 않는다.

## 확인한 문제와 검증의 한계

- 실제 브라우저에서 SOXL의 투자 대상·산업·수익 구조·일일 복리 예시·환율 답변과 추가 질문을 확인했다. 다음 질문의 재추천과 반복 보조 문장을 수정했다.
- 용어 창을 실제 클릭했을 때 개발 모드에서 바로 닫히는 문제를 발견했다. 문단 밖 포털과 네이티브 모달로 수정하고 용어 이동·Escape·본문 초점 복귀를 재검사했다.
- 환율을 누르면 회사 매출·비용 해설이 바로 나오는 맥락 문제도 발견했다. 단어의 기본 뜻과 개인의 원화 평가 예시를 우선하는 공통 정의를 추가했다.
- 301개 상품의 정적 렌더 검사는 전체 사용자 이해 검증이 아니다. 모든 회사의 사업 설명·최신 구성 비중·당일 변동 원인을 새로 채운 작업이 아니다.
- 루트의 전체 검사에는 기존 보관 소스 타입 오류, Node 테스트 파일의 Vitest 혼입, 브랜드 미리보기 문구 검사 문제가 있다. 현재 앱 소스 검사와 별도 Node 검사, 격리 빌드를 구분해 기록한다.
- 후속 운영 반영 요청에 따라 실제 Adg 소스1,122개를 해시 대조 복원하고 18파일만 선택 적용했다. 최종 `dpl_8ZsX5yAzwvfniLw7Bw4c4hj5jGq2` READY가 joobi.kr에 연결됐다. 로컬 원본 기준2,032/원격2,029검사 통과. 운영 SOXL7질문·용어 이동/복귀·데스크톱/390px 모달 배치, MSFT 산업 입구를 확인했다. 다크·물리적 모바일·전체 의미 검수·신규 개선 수집기 실제 운영 순회는 남아 있다.
- 앱 소스 2,172개·품질엔진 58개 검사와 앱 소스 타입·선택 ESLint·격리 빌드가 통과했다. SOXL 7개 질문과 SGOV의 국채·상품 설명을 실제 Chrome에서 확인했다. 자세한 근거와 미검증 범위는 `artifacts/instrument-exploration-20261102/REPORT.md`에 기록했다.

## 경쟁과 사용자 검증

토스의 공식 기술 설명에는 AI 시그널·실시간 이슈·어닝콜·AI 증시 캘린더와 평가·개선 구조가 소개돼 있다. 따라서 쉬운 문구·AI 설명·개선엔진의 존재만으로 경쟁 우위를 주장하지 않는다.

검증할 가설은 토스를 이미 쓰는 초보자가 주비를 통해 자신의 투자에서 달라진 점과 다음 확인할 일을 더 잘 이해하고 자발적으로 다시 찾는가다. 실제 사용 관찰·인터뷰·반복 이용·해결한 질문을 함께 보며, 방문·클릭 증가를 이해나 시장성으로 대체하지 않는다. 이 사용자 검증은 실행 전이다.
