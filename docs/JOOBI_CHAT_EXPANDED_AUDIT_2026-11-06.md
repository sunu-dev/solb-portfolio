## 변경
- AskJoobi의 LearningDesk CSS 의존성을 제거. 답변·비교·근거·출처·후속 질문을 JoobiChat에 통합.
- 가격 카드 여백14px·제목14px·숫자17px·보조12px. 상승/하락 공통 색상과 부호 유지.
- 비교 상대 없는 단일 지수는 “가격 변화”, 여러 대상이면 “같은 기간의 움직임”. 장중 최저와 마지막 가격을 구분하고 0%를 “같았어요”로 표시.
- 아래 내용 더 보기 버튼을 읽는 영역 아래의 별도 공간에 놓아 본문과 겹치지 않음.
- 첫 전송 버튼 “물어보기”, 인접한 AI 전송 안내 유지. 키보드 Enter만으로 최초 동의하지 않는 기존 동작 유지.
- 일일 횟수 소진 오류는 하단 안내 한 번으로 표시하고 작성한 질문 유지. 다른 실패 알림은 유지.
- 접힌 거래시간 안내의 자체 하단선 제거. 평가손익의 구획선 하나 유지.
- A 주식사전은 내용이 짧아도 저장 안내·퀴즈 버튼이 수첩 아래에 위치하도록 flex 영역 수정.
