# 주비 워드마크 폰트 비교용 서브셋

Google Fonts에서 영문 `JOOBI` 워드마크에 필요한 글자만 포함하도록 생성한 내부 비교용 서브셋입니다.
최종 폰트를 선택하면 선택하지 않은 파일은 제거하고, 선택한 폰트의 원본 라이선스 문서를 함께 보관해야 합니다.

- 화면: `/brand-preview`, `/brand-preview/lockup-30`
- 원본: https://fonts.google.com/
- 후보군: 기존 20종 + Onest·Inter Tight·Figtree·Epilogue·Red Hat Display·League Spartan·Space Mono·IBM Plex Mono·Bodoni Moda·Yeseva One
- 용도: 영문 워드마크 30종 폰트 비교
- 상태: 최종 브랜드 폰트 선택 전 임시 자산
